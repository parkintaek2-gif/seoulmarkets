3-e. [**9/3 신설**·상시 · **전 유닛**] **새롭게 확인된 것은 «문서»로 써서 다 공유한다.**
     사장님 원문: 「1. 오늘처럼 여러 세션들이 모두 나서 **함께** 일하니 얼마나 좋은지 모르겠다.
     **계속 이렇게 작업하며 스스로 발전하라** 2. **새롭게 확인된 것들은 문서로 작성해서
     다 공유하라고 지시해**」
     ```
     자리    docs/발견/YYYY-MM-DD_결론.md   ← 새로 열었다. 목록은 docs/발견/README.md
     자      node scripts/check-findings.mjs  (npm test 에 물려 있다)
     ```
     ⛔ **`docs/세션간-메모.md`에 한 줄 적는 것은 «공유»가 아니다.** 그 파일은 17만 줄이 넘는다 —
        오늘 알아낸 것이 내일이면 아무도 못 찾는다. 실제로 그렇게 잃은 것이 여럿이다
        (「이벤트 캘린더가 이미 있는데 안 보고 콘텐츠 기획을 새로 썼다」 2026-08-02).
     ✅ 문서마다 다섯 가지를 갖춘다 — 검사가 이 다섯을 «잰다».
     ```
     1. 결론을 제목에            「노출 470건이 우리 404 로 샜다」처럼 제목이 결론이다
     2. 어떻게 쟀나              돌린 명령·본 파일·표본 수. 다음 사람이 다시 잴 수 있게
     3. 잰 것과 판단을 갈라 적기   실측은 실측으로, 내 생각은 「제 판단」으로
     4. 못 잰 것을 「못 쟀다」로    ⛔ 0 으로 채우지 않는다
     5. 목록(README)에 올랐나     목록에 없으면 공유가 안 된 것이다
     ```
     ⭐ **앞선 결론을 «물린» 것도 발견이다.** 틀렸다는 기록이 남아야 다음 사람이 옛 결론을
        되살리지 않는다. 5번은 9/3 하루에 같은 주제로 진단을 두 번 물렸다.
     🔴 이 검사가 «자기 거짓말»을 한 것을 잡아 고쳤다 — 절 제목만 있고 속이 비었는데
        제목에 「제 판단」 글자가 있어 초록을 냈다. **제목은 약속이고 속이 내용이다.**
        이제 절마다 속이 몇 줄인가를 센다.
