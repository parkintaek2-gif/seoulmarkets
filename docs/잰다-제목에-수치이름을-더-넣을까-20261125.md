# 제목에 수치 이름을 하나 더 넣을까 — 재서 **접었다** (2026-11-25 00:5x · 5번)

## 하려던 것

`report/area` 258장 제목이 「○○구 고등학교 **진학률** N곳」이다.
지면 본문에는 「학급당 학생 수」 값(`학급글자`)이 이미 있는데 제목에는 없다.
그래서 제목을 「○○구 고등학교 진학률·학급당 학생 수 N곳」으로 넓히려 했다.
근거는 2026-11-18 측정이었다 — 「의정부시 고등학교」 0개 → 「… 진학률」 6개.

## 재 보니 가설이 틀렸다

네이버에 손님이 치는 그대로 쳐서 쟀다 (`scripts/잰다-네이버에서-우리가-뜨나.mjs`).

| 친 말 | 제목에 그 말이 | 우리 링크 |
|---|---|---|
| 부평구 고등학교 학급당 학생 수 | **없다** | ✅ 6개 |
| 화성시 고등학교 학급당 학생 수 | **없다** | 🔴 없다 |
| 부평구 고등학교 진학률 (대조군) | 있다 | ✅ 6개 |
| 의정부시 중학교 학급당 학생 수 | 있다 | 🔴 없다 |
| 의정부시 중학교 학급당 학생 수 + 백년지도 | 있다 | ✅ 6개 |

**제목에 그 말이 없어도 떴고(부평구), 있어도 안 떴다(의정부 중학교).**
제목의 낱말이 가른 것이 아니다.

## 그러면 무엇이 가르나

- 「… 백년지도」를 붙이면 어디서든 6개가 뜬다 → **색인은 되어 있다.**
- 이름을 안 붙이면 부평구는 뜨고 화성시·의정부(중)는 안 뜬다 → **같은 묶음 안에서도 갈린다.**
- 11-18 측정이 보여 준 것은 「제목에 수치 이름이 있어야 든다」가 아니라
  **「검색어가 좁아야 든다」**였다. 둘을 같은 것으로 읽은 것이 내 잘못이다.

네이버 `site:` 검색에 보인 우리 링크는 **140개**다. 지면은 13,908장이다.

## 그래서 정한 것

```
⛔ report/area 258장 제목 수정 — 접는다. 값을 치르고 얻을 것이 확인되지 않았다
✅ 먼저 할 것 — 색인을 넓힌다. 같은 제목 구조인데 뜨는 곳과 안 뜨는 곳이 갈린다
```

⚠ 표본이 다섯이다. 「제목을 고치면 는다」도 「고쳐도 안 는다」도 아직 말할 수 없다.
여기서 말할 수 있는 것은 **「제목을 고치는 것이 먼저가 아니다」** 하나뿐이다.
