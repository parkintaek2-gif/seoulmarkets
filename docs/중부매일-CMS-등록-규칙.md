# 중부매일 CMS 기사 등록 규칙 (5번)

사장님이 2026-11-26 에 주신 지시를 모은 것이다. 기사를 CMS 에 올리기 전에 이 문서를 읽는다.
도구는 `scripts/중부매일-스포츠-등록.mjs` 다. 지시가 새로 나오면 원문 그대로 여기에 더한다.

## 0. 먼저

- 중부매일 일은 복명복창하고 승낙받은 뒤에만 한다. 지시한 것만 한다. 「중단」이면 그 자리에서 멈춘다.
- 🔴 승인과 웹출판까지 5번이 한다 (사장님 2026-11-26 12시대 — 「**승인과 웹출판까지 다 해...입력시간을 그래야 확인할 수 있다며**」).
  앞서의 「미승인 체크 > 저장」은 이 말씀으로 바뀌었다. 기사를 올리면 승인으로 저장하고 웹출판을 누른 뒤,
  공개 화면에서 입력 시각이 작성 날짜인지 확인하고 그 값을 보고한다.
  ⚠ 승인하면 그 자리에서 독자와 포털에 나간다. 그래서 승인 전에 제목, 본문, 기자 정보, 분류, 사진과 사진설명, 키워드,
    관련기사, 입력 날짜를 수정 화면에서 전부 다시 읽는다. 하나라도 안 맞으면 승인하지 않고 미승인으로 두고 보고한다.
- 올라간 기사를 임의로 수정하거나 삭제하지 않는다.
- 메일은 승인이 필요할 때, 요청할 때, 메일로 보고하라고 따로 지시하신 때에만 보낸다.

## 1. 입력 시각 (가장 먼저 확인)

> 「날짜 제대로 확인하고 기사를 올려야 할 것 아니냐」
> 「다른 기사를 작성할 때도 입력 시간이 1970년이 아닌 작성 날짜가 되게 꼭 해.」

- 2026-11-26 에 올린 두 건(1516931, 1516943)이 입력 1970.01.01 09:00 으로 나갔다.
- 입력 시각은 수정 화면의 접힌 칸 「기사노출날짜」「노출시간」에 들어 있다.
- 처음 저장할 때 이 두 칸에 작성 날짜와 시각(지금보다 1분 앞)을 적어 넣는다. 비워 두지 않는다.
- 미래 시각을 넣지 않는다. 미래 시각이면 예약이 된다.
- 저장한 뒤 수정 화면을 다시 열어 두 칸이 오늘 날짜인지 읽고, 그 값을 보고에 적는다.
- 승인된 뒤에는 공개 화면의 입력 시각이 오늘인지 한 번 더 확인한다. 1970 이면 바로 보고한다.
- 원인(왜 수정 화면에서 승인 저장하면 날짜가 지워졌는지)은 아직 찾지 못했다. 찾으면 여기에 적는다.

## 2. 스포츠 기사 (e스포츠 제외)

> 「클로드 중부매일 계정이 작성하는 기사 중 스포츠(e스포츠 제외)를 네가 받아서 cms에 올려. user_id, 기자명 등 정보를 수정해.
>  다 작성하면 … 상태 메뉴에서 미승인 체크> 저장해놓고 나한테 이메일로 보고해.」

- 분류: 스포츠·연예 > 스포츠
- 기자: user_id jhlee, 기자명 「이지효 기자」, 메일 jhlee@jbnews.com, 본문 첫머리 「［중부매일 이지효 기자］」
- e스포츠 기사는 올리지 않는다(박인택 기자 그대로).
- 상태: 0번의 새 말씀대로 승인, 웹출판까지 한다.

## 3. 날씨 기사

> 「cms에 직접 올려. 기사분류=사회일반」
> 「추천키워드(해시태크) 내일날씨 청주날씨 대전날씨 세종날씨 천안날씨 충주날씨 오늘날씨...그리고 관련기사는 최근 날씨 기사 1건」

- 분류: 사회 > 일반
- 기자: 박인택 기자(parkintaek0521), 본문 첫머리 「［중부매일 박인택 기자］」
- 분량: 800자 이상(공백 제외). 올리기 전에 직접 센다.
- 키워드: 내일날씨, 청주날씨, 대전날씨, 세종날씨, 천안날씨, 충주날씨, 오늘날씨 (띄어쓰기 없이, 하나씩 넣고 엔터)
- 관련기사: 가장 최근 날씨 기사 1건
- 본문은 사장님 샘플을 따른다: `docs/샘플-중부매일-날씨-본문-20261126-사장님.txt`
  - 「포근하겠다」「맑다가 비가 한 시간 가량 내리겠다」처럼 읽히는 말로 쓴다. 「하늘 상태는 맑음으로 예보됐다」 같은 자료 말투를 쓰지 않는다.
  - 문단을 짧게 끊는다. 청주, 충청권 묶음, 충주, 대전, 천안, 세종, 모레와 글피 전망 순이다.
  - 작업용 메모(「앞서 나간 기사에는 …」)를 본문에 넣지 않는다.

## 4. 사진

> 「사진과 사진설명, 사진제목까지 다 올려」
> 「사진은 통신사 중 연합뉴스 및 연합뉴스가 전재하는 외국 통신사 건 사용가능해.」
> 「사진 박스에서 사진 바로 밑을 클릭하면 사진설명 넣을 수 있다. 앞으로 그렇게 해.」

- 쓸 수 있는 사진: 구단, 연맹, 대회 조직위 제공 사진, 연합뉴스 사진, 연합뉴스가 전재하는 외국 통신사 사진. 다른 언론사 사진은 쓰지 않는다.
- 사진은 사진 칸에 올린 뒤 가운데 정렬로 본문에 넣는다.
- 사진설명은 본문 사진 박스에서 사진 바로 밑 칸에 넣는다. 사진 수정 창의 「확인」으로는 저장되지 않았다.
- 사진설명 형식: 「▲ 설명 / 출처」. ▲ 는 중부매일 기사 전반의 표기다(2026-11-26 최근 기사 9건 확인).
- 사장님이 설명 문구를 주시면 그 문구를 고치지 않는다(「설명 고치지 말고」).
- 사진 속 장면과 날짜, 장소를 눈으로 확인한 뒤 설명을 쓴다. 선수 이름은 출처의 설명으로 확인된 때만 쓴다.
- 워터마크가 찍힌 파일을 올렸으면 보고에 적는다.

## 5. 관련기사

> 「관련기사에 같은 종목의 최근 경기 한 두건을 올려.」

- 스포츠: 같은 종목의 최근 경기 기사 1~2건
- 날씨: 최근 날씨 기사 1건
- 없으면 넣지 않고 보고에 「관련기사 없음」으로 적는다.

## 6. 저장한 뒤 반드시 다시 읽는 것

- 입력 날짜와 시각(오늘인가)
- 상태(미승인인가). 수정 화면의 상태 칸은 열릴 때 「승인」으로 표시되므로 공개 주소와 미승인 목록으로 확인한다.
- 기자 정보(user_id, 기자명, 메일), 분류, 제목, 부제
- 본문 사진 수와 사진설명, 키워드, 관련기사

## 7. 알려진 문제 (2026-11-26)

- 기사등록 화면(mode=input)은 열 때마다 기사 번호를 하나 잡는다. 한 기사에 한 번만 연다. 화면이 응답하지 않아 다시 열면 빈 번호가 남는다.
- 키워드는 셋째 것이 들어가지 않은 일이 두 번 있었다. 넣은 뒤 키워드 칸을 다시 읽어 빠진 것을 채운다.
- 가운데 정렬 버튼은 본문을 다시 적은 뒤에는 편집기에 커서가 있어야 동작한다.
- 승인 저장 때 확인창이 떠서 화면이 멎을 수 있다.
