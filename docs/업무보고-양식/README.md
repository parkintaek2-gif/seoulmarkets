## 2. 아홉 장의 차례

| 장 | 제목 | 무엇을 넣나 |
|---|---|---|
| 1 | 표지 | 오늘을 숫자 네 개로. 일자와 자리 번호 |
| 2 | 한 장 요약 | 오늘 한 일을 세 방향으로 갈라 카드 셋 |
| 3 | 방문자 | 사이트별 순방문자와 목표 대비 비율. 막대로 |
| 4 | 낸 콘텐츠 | 표. 낸 것 · 수 · 예상 효과 |
| 5 | 고친 것 | 카드 셋. 숫자를 크게, 설명을 작게 |
| 6 | 지금 하는 일 | 둘 또는 셋. 각각에 「효과」 한 줄 |
| 7 | 할 일 | 표. 할 것 · 근거 · 예상 효과. 효과가 큰 차례로 |
| 8 | 못한 것 · 막힌 것 | 두 칸으로 갈라서. 숨기지 않는다 |
| 9 | 다음 24시간 | 번호 매긴 다섯 줄 |

⛔ 「한 것」만 적고 「못한 것」을 비우지 않습니다. 못한 것이 없으면 「없습니다」라고 적습니다.
⛔ 수치를 적을 때는 어디서 나온 수인지 함께 적습니다.

```
1  deck.json 을 먼저 적는다 — order 에 아홉 장의 이름을 다 적는다
2  deck.css 와 표지 한 장을 함께 올린다
3  나머지 여덟 장을 세 장씩 나눠 올린다
4  아홉 장을 그려서 «눈으로» 본다
5  PDF 로 바꾼다 (1920 × 1080, 한 쪽에 한 장)
6  메일 본문을 적고 금지어 검사를 돌린다
7  보낸다
```
