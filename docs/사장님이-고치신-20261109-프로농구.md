## Ⅱ. 무엇이 달라졌나 — 한 줄씩

### 1. 틀 — 부제목과 사진 제목

| | 내가 올린 판 | 사장님 판 |

| 부제목 | `8일 프로농구 3경기 순위 변동 없어…서울 SK는 원주 DB를 81대65로 꺾고 2연패 끊어` | `[KBL 프로농구] 서울 SK는 원주 DB를 81대65로 꺾고 2연패 끊어` |
| 사진 | 설명만 | 설명 **위에 짧은 제목** — `서울 SK 김낙현` |

- **부제목 앞에 종목 태그를 단다** — `[KBL 프로농구]`
- 부제목의 앞부분(`8일 프로농구 3경기 순위 변동 없어…`)은 제목·첫 문단과 겹쳐서 **지우셨다**
- **사진마다 짧은 제목을 단다.** 「팀 이름 + 선수 이름」이다

### 2. 문장을 끊는다

```
내 판   김낙현은 3점슛 6개 중 4개를 넣어 17점을 올렸고, 안영준이 15점, 아이재아 힉스가 13점을 보탰다.
사장님  김낙현은 3점슛 6개 중 4개를 넣어 17점을 올렸다. 안영준이 15점, 아이재아 힉스가 13점을 보탰다.

내 판   원주 DB를 무너뜨린 것은 실책이었다. 원주 DB는 턴오버 20개를 범했다. 서울 SK는 8개였다.
사장님  원주 DB는 자멸했다. 턴오버 20개를 범했다. 반면에 서울 SK는 8개였다.
```

### 3. 설명하는 문장을 지우고 사실로 보여 준다

```
지워진 것   「두 팀은 득점하는 자리가 정반대였다」
            「안양 정관장은 그 반대였다」
            「승부는 마지막 10분이었다」
            「원주 DB를 무너뜨린 것은 실책이었다」
```

⭐ **내가 먼저 결론을 말하고 수치를 붙이는 꼴을 쓰고 있었다.** 사장님은 그 머리말을 지우시고
수치가 스스로 말하게 두셨다. 대신 한 줄짜리 판정은 **짧고 세게** 쓰신다 — 「원주 DB는 자멸했다」.

### 4. 스포츠 기사의 말

| 내 판 | 사장님 판 |
|---|---|
| 3점슛 31개를 던져 8개만 넣었다. 성공률 25.8%다 | 3점슛 31개를 **남발했다**. 이중 8개만 성공했다 |
| 성공률 44.8%다 | 성공률이 **무려** 44.8%**나 됐다** |
| 33점 9리바운드를 올렸지만 혼자 힘으로는 모자랐다 | 33점 9리바운드로 **맹활약했지만 팀을 패배해서 구할 수는 없었다** |
| 골밑을 파고들었다 | **집요하게** 골밑을 파고들었다 |
| 19점 12리바운드로 버텼다 | 19점 12리바운드로 버텼지만 **반전의 기회를 잡지 못했다** |
| (없음) | **승부의 여신은 이번에도 울산 현대모비스를 외면했다** |
| 부산 KCC는 창원체육관에서 | **디펜딩 챔피언** 부산 KCC는 초반 연패의 부진을 완전히 끊었다 |

⭐ 「좋다·나쁘다」를 피해 밋밋하게 쓰던 내 버릇이 **스포츠 기사에서는 맞지 않는다.**

### 5. 백분율보다 개수

```
내 판   원주 DB는 3점슛 31개를 던져 8개만 넣었다. 성공률 25.8%다.
사장님  원주 DB는 3점슛 31개를 남발했다. 이중 8개만 성공했다.      ← 성공률을 지우셨다
```

⚠ 다만 **44.8%·61.8%·60.8% 는 남기셨다.** 지운 것은 「25.8%」 하나다.
  남긴 것은 전부 **높아서 뜻이 있는 수**이고, 지운 것은 개수(31개 중 8개)로 이미 보이는 수다.

### 6. 지시어를 명사로 되돌린다

```
내 판   리바운드는 43대32로 앞섰지만 … 그 우위를 살리지 못했다
사장님  리바운드는 43대32로 앞섰지만 … 리바운드 우위를 살리지 못했다
```

### 7. 앞에서 말한 것을 되풀이하지 않는다

```
내 판   울산 현대모비스는 3승 9패가 돼 최하위에 그대로 남았다
사장님  울산 현대모비스는 3승 9패가 됐다          ← 첫 문단에 이미 「최하위」가 있다
```

### 8. 가장 센 수치를 문단 맨 앞으로

```
내 판   (흐름 문단) … 1쿼터는 18대15 …
        (다음 문단) 서울 SK가 앞선 시간은 34분 43초 … 한때 22점까지 달아났다.
사장님  서울 SK는 한때 22점까지 달아났다. 1쿼터는 18대15, 접전이었다. …
```

- **「한때 22점」을 흐름 문단의 첫 문장으로 올리셨다.** 문단 안에서도 두괄식이다
- ⛔ **「득점 우위 시간 34분 43초」는 지우셨다.** 내가 좋다고 넣은 수인데 독자에게는 와닿지 않는다

### 9. 진 팀 분석을 길게 끌지 않는다

```
지워진 문단   「창원 LG는 3점슛에 매달렸다. 35개를 던져 10개를 넣는 데 그쳤다.
              성공률 28.6%다. 자유투도 26개 중 16개, 61.5%에 머물렀다.」
```

세 번째 경기는 **이긴 팀 중심으로 한 문단**으로 줄이셨다. 골밑 득점(27대13)을 먼저,
2점슛 성공률(60.8%)을 뒤에 두셨다 — **눈에 보이는 수를 앞에.**
