## Ⅱ. 무엇이 달라졌나

### 1. 🔴 내가 과하게 고친 것을 **되돌리셨다**

농구 기사를 보고 「담백한 표현을 센 표현으로 바꾸라」로 읽었는데 그게 아니었다.

| 1번 판본(내가 처음 쓴 것) | 내가 고친 것 | 사장님이 실으신 것 |
|---|---|---|
| 모마가 26점으로 **가장 많이 득점했다** | 공격을 이끌었다 | **가장 많이 득점했다** ← 되돌림 |
| 킨델란이 23점으로 **버텼다** | 분전했다 | **버텼다** ← 되돌림 |

⭐ **센 표현은 승부가 갈린 대목에만 쓴다.** 선수 기록을 나열하는 자리는 담백하게 둔다.
  농구에서 「자멸했다·남발했다」를 쓰신 곳은 전부 **승부를 설명하는 문장**이었다.

### 2. 🔴 수치를 풀어 쓰지 않는다

```
내 판   공격 열 번 가운데 약 네 번을 혼자 맡았지만 성공률이 33.85%에 그쳤다
사장님  공격 점유율 38.69%로 높았지만 성공률은 33.85%에 그쳤다
```

쉽게 풀어 준다고 고친 것인데, **용어와 수치를 그대로 두는 쪽**을 고르셨다.

### 3. 대회 정식 이름을 리드 맨 앞에

```
내 판   [중부매일 박인택 기자] 한국도로공사가 8일 흥국생명을 …
        (대회 이름은 둘째 문단에)
사장님  [중부매일 박인택 기자] HK흥국금융 2026~2027 V-리그 여자부 1라운드에서
        한국도로공사가 8일 흥국생명을 …
```

### 4. 기술적인 집계는 통째로 빼셨다

```
빠진 문단   「한국도로공사는 공격 득점 63개·블로킹 11개·서브 4개로 78점을 직접 냈고
            상대 범실로 24점을 더 얻어 모두 102점이 됐다. 흥국생명은 …」
```

합계가 맞는지 보여 주는 계산은 독자가 읽지 않는다. **대신 비교되는 수치만 남기셨다** —
리시브 효율·공격 성공률·디그·블로킹 넷.

### 5. 되풀이와 곁가지를 지우신다

```
빠진 것   「1위는 2경기를 모두 이긴 IBK기업은행이다」      (이 경기와 무관)
          「흥국생명이 네 세트 가운데 가장 적은 13점에 묶였다」 (바로 앞 문장과 겹침)
          「경기 시간은 2시간 4분이었다」                  (세트별 시간이 본문에 있다)
          「승점을 3에서 6으로 늘려」 → 「승점6점으로」
          흥국생명의 다음 경기, 9일·10일 다른 경기 일정    (주인공 팀 일정만 남기셨다)
```

### 6. 사람의 말을 한 줄 넣으신다

```
내 판   흥국생명은 3세트에서 25대23으로 반격했다.
사장님  흥국생명도 가만히 있지만은 않았다. 3세트를 25대23으로 따라붙으며 반격에 성공했다.
```

### 7. 세트 설명의 순서 — 상황 · 점수 · 시간

```
내 판   1세트에만 37분이 걸렸다. 24점에서 갈리지 않아 듀스로 넘어갔고,
        27대27에서 한국도로공사가 연달아 2점을 따내 29대27로 가져갔다.
사장님  1세트부터 접전이었다. 듀스 끝에 한국도로공사가 연달아 2점을 따내 29대27로
        가져갔다. 37분이나 걸린 긴 세트였다.
```

**상황을 먼저, 점수로 보이고, 시간은 끝에 덧붙인다.** 「24점에서 갈리지 않아」·「27대27에서」
같은 설명은 빼셨다.

### 8. 부제목과 사진 제목

| | 내 판 | 사장님 판 |
|---|---|---|
| 부제목 | `[V리그 여자부] 1세트 29대27 듀스 접전 끝 3대1 승리…모마 26점·김세빈 15점` | `[V-리그 여자부] 모마 26점·김세빈 15점 활약하며 3대1 승리` |
| 사진 제목 | 한국도로공사-흥국생명 네트 앞 공방 | **한국도로공사와 흥국생명** |

- 대회 이름은 **`V-리그`** 다. 붙임표가 들어간다(KOVO 정식 표기)
- 부제목은 **「누가 무엇을 해서 어떻게 됐다」** 한 줄. 경기 내용을 넣지 않는다
- 사진 제목은 **팀 이름을 「와」로 잇는다.** 장면을 설명하지 않는다

## Ⅲ. 두 본보기를 합쳐 — 다음 경기 기사를 쓸 때 이 순서로 본다

```
1  부제목 = [대회 이름] + 누가 무엇을 해서 어떻게 됐다. 경기 내용은 안 넣는다
2  사진 제목 = 팀 이름(과 선수 이름). 장면 설명을 하지 않는다
3  리드 첫 문장에 대회 정식 이름을 넣는다
4  쿼터·세트마다 «그 점수»와 «합산 점수»를 같이 쓴다 (농구)
5  세트 설명은 상황 → 점수 → 시간 순서로 (배구)
6  문단마다 가장 센 수치를 맨 앞에
7  센 표현은 «승부가 갈린 대목»에만. 선수 기록 나열은 담백하게
8  용어와 수치는 그대로 쓴다. 쉽게 풀어 쓰지 않는다
9  합계가 맞는지 보여 주는 계산은 뺀다. 비교되는 수치만 남긴다
10 앞 문장과 겹치는 것, 이 경기와 무관한 것, 상대 팀 일정은 뺀다
11 한 문장에 둘을 붙이지 않고 끊는다
```

⛔ **쓰지 않는 것** — 득점 우위 시간 · 관중 수(매진 제외) · 경기 총 시간 ·
  그날 경기가 없던 팀 이야기
