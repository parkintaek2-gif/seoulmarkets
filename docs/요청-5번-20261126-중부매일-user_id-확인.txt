[5번] 복명복창 — 중부매일 user_id 확인 (승낙 요청)

사장님 지시: 슬라이드 7장에서 표시하신 부분을 「확인해, 중요한거야」

확인할 것 세 가지
1. 새 기사는 작성한 로그인 계정의 user_id가 들어가는가 (슬라이드에는 추정으로 적었습니다)
2. 네이버로 전송되는 자료에 user_id가 실리는가
3. 회원 관리 메뉴에 기사 소유자를 다른 계정으로 옮기는 기능이 있는가

공개 화면에서 이미 확인한 것 (CMS를 열지 않고 측정)
- 네이버 뉴스 검색에서 중부매일 기사는 네이버 안의 기사 페이지가 아니라 jbnews.com 주소로 바로 연결됩니다 (오늘 검색 결과의 중부매일 기사 4건 모두).
- 공개 기사 페이지에서 user_id는 「기자 프로필 보기」 링크 주소에만 있습니다. 기사 메타 정보에는 기자 성명만 있습니다.
- 그래서 네이버 화면에는 user_id가 보이지 않습니다. 다만 CMS가 네이버로 보내는 전송 자료 원문에 user_id가 들어 있는지는 CMS 안에서만 확인됩니다.

승낙을 구하는 것: CMS 읽기 전용 확인
아래만 합니다. 저장, 승인, 삭제, 수정 버튼은 누르지 않습니다.
가. 기사 수정 화면 1건을 열어 숨은 값(user_id 등)과 관리자 메뉴 목록을 읽습니다.
나. 새 기사 작성 화면을 열어 user_id 칸에 어떤 값이 미리 들어 있는지 읽고, 저장하지 않고 닫습니다.
다. 포털 전송 관련 메뉴와 회원 관리 메뉴를 열어 화면만 읽습니다.

하지 않는 것
- 시험용 기사를 만들지 않습니다. 새 기사를 실제로 저장해 보는 시험은 따로 지시하실 때만 합니다.
- 박인택 명의 「오늘의 운세」 예약 20편은 열지 않습니다.

「확인 진행해」 한 줄 주시면 바로 시작하고, 결과는 슬라이드 7장을 고쳐서 보고드립니다.

참고: 방금 읽기 전용 확인을 시작하려 했으나 자동 권한 검사가 막았습니다. 중부매일 건은 승낙 뒤에만 실행한다는 규칙과 같은 방향이라 우회하지 않았습니다.
