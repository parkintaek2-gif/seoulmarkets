# 게재본 샘플 넉 건 — 사장님이 「기사 샘플을 참조해서 데스킹해」라고 주신 것

2026-11-11 · 5번이 받아 적음 · **원문 그대로 둔다. 요약하지 않는다.**

받은 것은 넉 건이다. 앞의 셋은 11월 11일 게재본, 넷째는 11월 10일 야구결산 1회다.

```

② [KBL] 소노 86-79 현대모비스                2026.11.11 09:28

④ [2026 프로야구 결산 ①] 타고투저             2026.11.10 16:30
```

## 🔴 ③은 «내가 데스킹해 올린 것»이다 — 무엇이 깎였는지 그대로 본다

이 한 건이 넉 건 중 가장 값이 크다. 내가 보낸 판과 게재본이 나란히 있어
**데스크가 무엇을 덜 했어야 했는지**가 글자로 드러난다.

### 제목 — 꼬리를 떼셨다

```
내 것    [날씨] 12일 청주 아침 2도·낮 15도…11일과 비슷, 일교차 13도
게재본   [날씨] 12일 청주 아침 2도·낮 15도…11일과 비슷
```

⭐ 제목에 셋을 넣으면 셋 다 안 읽힌다. **일교차는 본문이 할 일**이다.

### 부제 — 절반으로 줄이셨다

```
내 것    12일 충청권 낮에는 맑고 밤 8시부터 구름 증가, 아침 최저기온
         청주·충주 2도 대전·세종·천안 3도…13일은 기온 상승
게재본   충청권 맑은 뒤 구름 많아져…아침 최저 충주 2도 대전·세종·천안 3도
```

⭐ **제목에 이미 있는 말을 부제에서 뺀다.** 「12일」·「청주」가 제목에 있으므로 부제에서 지워진다.
⭐ 「밤 8시부터 구름 증가」 같은 시각은 부제가 아니라 본문의 몫이다.
⭐ 13일은 본문 마지막 한 줄로 충분하다. 부제까지 따라가지 않는다.

### 본문 — 수치 나열과 요약 문장이 통째로 빠졌다

| 내가 쓴 것 | 게재본 |
|---|---|
| 아침 최저기온은 **청주 2도**, 충주 2도, 대전 3도… | **청주를 뺐다** — 리드에 이미 있다 |
| 「충주가 5개 지역 중 가장 낮고, 세종과 천안이 가장 높다」 | **통째로 뺐다** — 표를 말로 다시 읽는 문장이다 |
| 11일 비교 세 문장(도시별 수치까지) | **「기온 변화는 거의 없다」 한 줄** |
| 「5개 지역 모두 오전 10시부터 저녁 7시까지는 맑겠다」 | **뺐다** |
| 「아침 7시 기온은 5개 지역 모두 3도로 예보됐다」 | **문단째 뺐다** |
| 「일교차는 …에 이른다」 | 「…**로 차이가 많이 나겠다**」 |
| 「출근 시간과 한낮의 기온 차가 커 겉옷이 필요하겠다」 | 「출근 시간에 **쌀쌀해** 겉옷이 필요하겠다」 |

⭐⭐ **「전날과 비교」는 수치를 늘어놓으라는 뜻이 아니었다.**
사장님이 「전날인 11일 날씨와 기온 비교」라고 하셨을 때 내가 낸 것은 도시 다섯 곳의
낮 최고기온을 또 한 번 나열한 세 문장이었다. 게재본은 **한 줄**이다.
변화가 없으면 없다고 한 줄로 쓰는 것이 비교다.

⭐ **같은 수를 두 번 쓰지 않는다.** 리드에 청주가 있으면 목록에서 청주를 뺀다.
⭐ **표를 말로 다시 읽는 문장을 쓰지 않는다.** 「가장 낮고 가장 높다」는 독자가 읽으면 보인다.
⭐ 말투 — 「…에 이른다」보다 「…로 차이가 많이 나겠다」, 「기온 차가 커」보다 「쌀쌀해」.
   사람이 느끼는 말로 쓴다.

### 🔴 사진 — 날씨에도 사진이 들어갔다

게재본에 연합뉴스 사진이 붙어 있다.

```
겨울 따뜻하게 보낼 수 있게
아침 최저 기온이 영하권으로 내려가며 일교차 큰 날씨를 보인 10일 경기도 안성시
한 장작업체에서 관계자가 장작을 정리하고 있다. / 연합뉴스
```

⭐ 앞서 「날씨는 사진 없음」으로 적어 둔 것을 **고친다.** 날씨 기사에도 사진이 들어간다.
   날씨 자체를 찍은 사진이 아니라 **그 날씨를 사는 사람**을 찍은 사진이다.

## ①② 스포츠 두 건에서 다시 확인되는 것

### 제목은 «무엇이 걸려 있었나»를 담는다

```
① IBK기업은행, SOOP에 3-1 개막 3연승 질주
② ‘꼴찌 대결’ 소노, 현대모비스에 86-79 승…5연패 탈출
```

점수만으로는 제목이 안 된다. **개막 3연승·꼴찌 대결·5연패 탈출**이 제목을 만든다.
경기 기록에는 없고 **대회 이력**에 있는 것이다.

### 부제는 사람과 수다

```
① 최정민 19점 이주아 17점 중앙 36점 합작…SOOP는 3연패 늪
② 오브라이언트 29점 12R 더블더블·이정현 26점 활약… 현대모비스 4연패 수렁
```

⭐ **두 팀을 다 적는다.** 이긴 쪽만 적지 않는다 — 진 쪽의 처지가 기사의 절반이다.
⭐ 「중앙 36점 합작」처럼 **내가 더한 수**를 하나 넣는다. 기록실에 그대로 있는 수만 적으면
   자체기사가 아니다.

### 끝 문단은 순위와 다음을 가리킨다

```
① 승점 9점으로 단독 선두 / 신생팀 SOOP은 창단 첫 승을 다음 경기로 미뤘다
② 6위 한국가스공사와 한 경기차로 좁히며 순위 반등을 노릴 수 있게 됐다
```

### 사람 이름에는 «한 일»이 붙는다

「3세트 마지막 고비에서는 이주아가 블로킹으로 동점 흐름을 끊어냈다」
「1세트 마지막 포인트는 육서영의 블로킹에서 나왔다」
— 이름만 부르지 않는다. **그 사람이 경기를 어떻게 움직였는지**를 붙인다.

## ④ 야구결산 1회 — 결산의 뼈대

```
질문 → 수치 → 그 수치가 뜻하는 것 → 충청권
```

- 첫 문단이 **질문의 답**이다. 「순위가 이렇게 흔들린 배경은 무엇일까?」를 던지고
  바로 「타고투저」로 답한다.
- **모든 수치에 지난해 같은 수치가 붙어 있다.** 0.262→0.268, 1천191→1천366, 4.31→4.66.
  한 해 수치만 있는 문장이 없다.
- **내가 맞춘 수**가 들어 있다 — 「리그 평균이 0.35 오르는 동안 KT만 제자리」,
  「LG 상승 폭 1.02는 리그 평균의 세 배」. 기록실에 그대로 있는 수가 아니다.
- **충청권(한화)이 한 단락 전체**다. 끼워 넣기가 아니다.
- 마지막은 **대전한화생명볼파크 관중**으로 닫는다. 충청권 독자의 자리로 돌아온다.

## 데스킹할 때 이 파일에서 꺼내 쓰는 일곱 줄

```
① 제목에 쓴 말을 부제에서 다시 쓰지 않는다. 리드에 쓴 수를 목록에서 다시 쓰지 않는다
② 표를 말로 되풀이하는 문장을 지운다 (「가장 높고 가장 낮다」)
③ 비교는 길이가 아니라 결론이다 — 변화가 없으면 한 줄로 끝낸다
④ 제목은 점수가 아니라 «무엇이 걸려 있었나»다
⑤ 부제에는 진 쪽도 적는다. 그리고 내가 더한 수를 하나 넣는다
⑥ 사람 이름에는 그 사람이 경기를 움직인 장면을 붙인다
⑦ 수치마다 지난해 같은 수치를 붙인다. 한 해만 있는 수는 뜻이 없다
```
