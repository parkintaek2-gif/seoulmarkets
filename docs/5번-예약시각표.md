# 5번 예약 시각표 — **세션이 바뀌면 이 표대로 다시 건다**

> 🔴🔴 **예약은 세션에만 산다.** 디스크에 안 적히고, 이 창이 닫히면 사라지며, 7일이면 저절로 끝난다.
> 그래서 이 표를 저장소에 둔다. **새 창이 열리면 `CronList` 로 견주어 보고 빠진 것을 다시 건다.**
> ⛔ 「전에 걸어 뒀다」를 「지금 걸려 있다」로 읽지 않는다 — 한 번 재서 본다.

## 왜 분을 이렇게 두었나 (2026-10-06)

사장님: 「**스포츠기사 예약시간에 맞춰서 줘라**」

그 전까지 최근 7일 24회차 가운데 **19회차가 늦었다(가운데값 49분)**.
09시→10:03 · 10시→10:52 · 11시→11:54 · 14시→14:47.

재 보니 까닭이 **둘**이었고, 둘이 안 갈라져 있었다 —

```
① 내가 늦게 가나    거두기 예약(:22)을 매시 점검(:13)이 깔고 앉았다.
                    예약은 REPL 이 한가할 때만 뜬다. 점검이 길게 돌면 거두기가 통째로 밀린다
② 저쪽이 늦게 쓰나   11시 회차가 11:00 이 아니라 «11:08 에 시작»해 11:16 에도 쓰는 중이었다
```

⛔ ①만 고치고 거두기를 :07 로 당겼더니 11:07 에 「회차 없음」이었다 — **헛걸음만 늘었다.**
⇒ 둘 다 보고 분을 정했다. 그날 11시 기사는 **11:17 에 나갔다(20분)**.

## 재는 자 둘 — ⛔ 「고쳤다」로 끝내지 않는다

```bash
node scripts/잰다-기사가-제때-나갔나.mjs      # 회차 시각 대비 몇 분에 나갔나 (제때/늦음/못잼)
node scripts/잰다-회차가-몇분에-떴나.mjs      # 글이 «몇 분에» 다 되나 — 예약 분을 이것으로 맞춘다
```

⛔ 둘째 자가 `안전한분()` 에서 **null** 을 주면 아직 줄이 모자란 것이다.
   **모자란 자료로 예약을 옮기지 않는다.** 며칠 더 쌓고 옮긴다.

⚠ 지금 분(`7,19,27`)은 **하루치 실측**으로 정한 것이다. 수가 쌓이면 다시 맞춘다.
