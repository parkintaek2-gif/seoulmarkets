### 🔴🔴 사장님이 고치신 꼴 (2026-10-22 네 편 실측)

사장님 — 「**내가 수정해서 내보낸 기사들이야 다음에 기사 작성시 참조해**」

이것은 사장님이 손수 고쳐 내보내신 네 편에서 뽑은 것입니다. 지어낸 규칙이 아닙니다.
원문 — `docs/고정업무-마커/중부매일-사장님이고치신것/`

#### ① 「길게」는 분량이 아니라 **내용**입니다

사장님이 「기사 너무 짧다」 하셔서 날씨를 10문단으로 늘렸더니,
사장님은 그것을 **6문단으로 줄여** 내보내셨습니다.

```
✅ 늘려야 할 때   «사실»이 빠져 있다 — 상대가 누구인지 · 왜 그렇게 됐는지 · 그 사람이 누구인지
⛔ 늘리면 안 될 때  사실은 다 있다 — 거기에 설명 · 곁가지 · 조언을 덧붙이는 것
```

아시안패러게임은 446자에서 2천 자대로 늘린 것을 **그대로** 쓰셨습니다.
거기서 늘린 것은 곁가지가 아니라 **없던 사실**이었습니다 —
결승 상대가 누구이고, 그 선수가 어떤 사람이며, 어떻게 여기까지 왔는지.

**소재마다 알맞은 길이가 다릅니다** (사장님이 내보내신 네 편 실측)

```
날씨            6문단      예보 수치와 어제 견주기. 그 이상은 덜어내십니다
경기 결과        9문단      결과 · 기록 · 순위 · 다음 일정
사람 · 여러 종목  12문단     선수마다 한 문단씩
논란 · 국감      20문단 넘김  말과 반응이 많을 때는 길어도 좋습니다
```

⛔ 문단 수를 채우려고 없는 사실을 지어내지 않습니다. 가장 큰 잘못입니다.

#### ② 제목 맨 앞에 **갈래**를 밝히십니다

```
내 것   내일 충청권 낮 22도, 오늘보다 6도 올라
사장님  [날씨] 내일 낮 기온 오늘보다 6도 올라

내 것   삼성 개막 6연승, 23년 만의 구단 타이 기록
사장님  프로농구 삼성 개막 6연승 디펜딩 챔피언 KCC 97대 86 제압
```

- 날씨는 `[날씨]` 를 제목 맨 앞에.
- 스포츠는 **종목 이름**(프로농구 · 프로야구)을 제목 맨 앞에.
- 대회 이름은 **부제 맨 앞**에 — `[아시안패러게임] 66세 김옥금 양궁 2연패…`

#### ③ 제목에 핵심 사실, 부제에 나머지 — 제가 둘을 **거꾸로** 놓았습니다

```
내 것   제목  삼성 개막 6연승, 23년 만의 구단 타이 기록
        부제  디펜딩 챔피언 KCC 97대 86으로 제압하며 단독 선두, 칸터 30점… KCC는 4연패로 최하위

사장님  제목  프로농구 삼성 개막 6연승 디펜딩 챔피언 KCC 97대 86 제압
        부제  23년 만에 구단 타이 기록… 칸터 30점 앞세워 단독 선두
```

- **누가 누구를 어떻게 이겼나**가 제목입니다. 기록과 의미는 부제로 내립니다.
- 부제에 셋을 넣지 않으십니다 — 「KCC는 4연패로 최하위」를 빼셨습니다.
- 제목에 쉼표를 덜 쓰십니다. 붙여 쓰십니다.

#### ④ 메달을 제목에 쓰는 것은 **괜찮습니다**

「장애인 대회는 메달을 제목에 올리지 않는다」를 제가 넓게 읽어 「금메달」을 뺐는데,
사장님은 되살려 내보내셨습니다 — 「14대 14에서 찌른 마지막 한 점, 휠체어펜싱 조은혜 금메달」.

```
⛔ 하면 안 되는 것   메달 «목표»와 종합 «순위»를 제목에 세우는 것
✅ 해도 되는 것     한 선수가 무엇을 이뤘는지 적는 것
```

#### ⑤ 사진 — 긴 기사에는 **여러 장**, 해당 문단 «앞»에

패러게임 기사에 사장님이 사진을 **세 장** 넣으셨습니다. 맨 위에 몰지 않으셨습니다.

```
[사진1 조은혜]   ← 머리
  조은혜 문단들
[사진2 김옥금]   ← 김옥금 문단 «앞»
  김옥금 문단
[사진3 주정훈]   ← 주정훈 문단 «앞»
  주정훈 문단
```

- **종목이 바뀌는 자리마다** 사진을 놓으십니다. 선수가 여럿이면 사진도 여럿 찾습니다.
- 사진 제목(「끝까지 치열하게」·「환호하는 삼성」)을 캡션과 **따로** 답니다.
- 출처는 거의 **연합뉴스**입니다. 제가 KBL 공식 사진 주소를 드렸지만 연합뉴스 것을 쓰셨습니다.
  ⇒ 제공처 주소 찾기는 연합뉴스 사진이 «없을 때» 할 일입니다.
- ⚠ 한 선수가 여러 종목에 나가면 **사진 캡션의 종목과 본문의 종목이 맞는지** 봅니다.

#### ⑦ 말이 오간 기사는 **묻고 답한 것을 짝으로** 붙입니다

```
「선수들이 어려움을 호소했느냐」          →  「그렇다」
「96라인의 문제 제기가 쌓여 온 것 아니냐」  →  「대답드리기가 좀 죄송하다」
```

물음과 답을 붙여 놓으면 **피한 답이 드러납니다.** 따로 적으면 안 보입니다.
답변을 늘어놓기 전에 그것이 무엇이었는지 **한 줄로 세우십니다** —
「이 부회장은 그러나 본질을 회피하는 듯한 답변으로 일관했다.」

반응·댓글이 많으면 **갈래로 묶습니다.** 갈래마다 한 문장으로 열고 그 아래 붙입니다 —
「비판은 선수에게만 향하지 않았다. 협회와 축구 행정을 지적한 댓글이 상당수였다.」

**⑩ 🔴 본문은 «1,000자»를 넘긴다**

사장님 지시 (2026-11-01): 「**기사는 1,000자를 넘어야 한다**」
  · 「**최소 1,000자를 쓰라고. 1,000자 이하가 아니고.**」

- **본문이 1,000자를 넘어야 한다.** 제목·부제목·사진 설명·근거 표는 세지 않는다.
  공백을 뺀 기사 몸통만 센다. 넘지 않으면 그 기사는 **덜 쓴 것**이다.
- ⛔ 세 문단, 네 문단짜리 기사를 내지 않는다. 보통 **여덟 문단 안팎**이면 1,000자가 된다.
- ✅ 채우는 길은 «사실»이다 — 이닝·세트·구간별 흐름, 선수 기록 수치,
  직전 경기까지의 성적, 다음 경기 일정과 상대, 순위표에서 이 경기가 갖는 뜻.
- ⭐ 1,000자는 «바닥»이다 — 천장이 아니다. 1,000자를 못 넘기면 기사가 아니라는 뜻이지,
  넘길수록 좋다는 뜻이 아니다. 사실이 다 들어갔으면 거기서 맺는다.
- ⛔ 글자 수를 채우려고 없는 사실을 지어내지 않는다. 같은 말을 바꿔 쓰며 늘리지도 않는다.
  채울 것이 모자라면 **사실을 더 찾아서** 채운다. 사실이 없으면 늘리지 않는다 —
  **팩트 규칙이 이 규칙보다 앞선다.**
- ⭐ 다 쓰고 나서 **스스로 센다.** 1,000자가 안 되면 내지 말고 더 쓴다.
