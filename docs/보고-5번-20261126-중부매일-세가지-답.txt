[5번] 중부매일 세 가지 질문의 답 (2026-11-26)

읽기만 했습니다. CMS에서 저장, 승인, 삭제, 전송 버튼은 누르지 않았습니다.

질문 1. 네이버에 전송하는 정보에 기사의 어떤 것들이 있는가
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

결론: 전송 항목의 전체 목록은 확인하지 못했습니다. 네이버가 실제로 받아서 갖고 있는 항목은 아래와 같습니다.

네이버 검색 화면에서 확인한 것 (오늘 중부매일 기사 12건 분석)
- 제목: 있음. 검색 결과에 그대로 표시됩니다.
- 본문: 있음. 본문 첫머리부터 요약으로 표시됩니다.
- 기사 주소: 있음. jbnews.com 기사 주소로 연결됩니다.
- 노출 시각: 있음. 「13시간 전」처럼 표시됩니다.
- 대표 사진: 있음. 네이버 서버에 복사본이 저장돼 있습니다 (사진 파일을 직접 열어 확인).
- 언론사 번호와 기사 번호: 있음. 네이버가 중부매일을 5283번으로, 기사마다 자체 번호를 매깁니다.
- 기자명 (별도 항목): 화면에 없습니다. 기자 성명은 본문 첫머리 안에만 보입니다.
- 기자 메일: 화면에 없습니다.
- user_id: 화면에 없습니다.

여기서 알 수 있는 것
- 사진이 네이버 서버에 복사돼 있으므로, 네이버는 링크만 가져가는 것이 아니라 CMS가 보낸 기사 자료를 받아 저장합니다.
- 네이버 화면에서 기자가 드러나는 자리는 본문 첫머리의 「［중부매일 ○○○ 기자］」뿐입니다. 박인택 바이라인 기사 8건이 모두 「［중부매일 박인택 기자］」로 시작합니다.
- 그래서 스포츠 기사는 본문 첫머리를 바꾸고 수정 전송이 되어야 네이버 표시가 바뀝니다. user_id, 기자명, 메일만 바꿔서는 네이버 화면이 그대로일 가능성이 큽니다. 수정 전송이 자동으로 나가는지는 11월 30일 첫 작업 때 전송로그로 확인하겠습니다.

CMS 안에서 확인한 것
- 「기사전송」 메뉴: 기사마다 네이버, 다음, 줌, 언론재단으로 전송된 시각이 나옵니다.
- 전송로그 「보기」: 「26.11.22 18:57 네이버 신규 전송성공 자동전송」 같은 결과 줄만 있습니다. 보낸 자료의 내용은 나오지 않습니다.
- 「채널설정」 메뉴: 포털별 분류 코드를 맞추는 표만 있습니다.
- CMS 설명서: 전송 항목에 대한 설명이 없습니다.

확인하지 못한 것
- 전송 자료 원문에 화면에 안 보이는 항목 (기자명, 메일, user_id, 분류 코드)이 들어 있는지.
- ND소프트에 물으실 때: 「네이버 전송 자료에 들어가는 항목 전체, 특히 기자명, 메일, user_id, 1차 2차 3차 분류 코드 포함 여부」

질문 2. CMS 안에서 기자 프로필을 수정할 수 있는가
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

결론: 일부만 수정할 수 있습니다. 회원ID와 성명은 수정할 수 없습니다.

회원 「정보수정」 화면 (지금 로그인된 계정 parkintaek0521 의 화면에서 항목만 읽음)
- 회원ID (user_id): 수정 불가. 잠겨 있습니다.
- 성명: 수정 불가. 잠겨 있습니다.
- 이메일: 수정 가능
- 연락처: 수정 가능
- 프로필사진: 수정 가능 (파일 올리기)
- 등급 (일반회원, 시민기자, 사진기자, 기자, 데스크): 수정 가능
- 필자표시 (논설위원, 기자, 시민기자 등 호칭): 수정 가능
- 관리권한, 상태: 수정 가능
- 필명, 직업, 소속, 소개, 블로그: 화면에 입력 칸이 없고 숨은 값으로만 있습니다.

함께 확인한 것
- 새 기사 작성 화면을 열면 로그인한 계정의 user_id, 기자명, 메일이 미리 들어갑니다 (parkintaek0521 로 확인). 슬라이드에 추정으로 적었던 내용이 확인됐습니다. 이지효 기자 계정으로 로그인해 보지는 않았습니다.
- 기사 소유자를 다른 계정으로 한꺼번에 옮기는 기능은 찾지 못했습니다. 회원목록, 섹션일괄변경, 필자표시관리, 기사검색 화면에 그런 버튼이 없습니다.
- 그래서 기사의 user_id를 바꾸는 길은 기사마다 수정 화면의 숨은 값을 바꿔 저장하는 지금 방식뿐입니다.
- 다른 기자의 정보수정 화면은 열지 않았습니다.

질문 3. 기사 주소에 1차, 2차, 3차 분류 코드까지 들어가는가
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

결론: 들어가지 않습니다. 주소에는 기사 번호만 있습니다.

- 네이버에 걸린 주소: 오늘 확인한 중부매일 기사 17건 모두 jbnews.com/news/articleView.html?idxno=기사번호 형식입니다. 분류 코드가 없습니다.
- 기사 페이지의 대표 주소: 같은 형식으로 기사 번호만 있습니다.
- 분류가 실제로 있는 곳: 기사 페이지 안쪽 메타 정보에 분류명으로 들어 있습니다. 1497785 는 1차 「오피니언」, 2차 「외부칼럼」, 3차 「문화칼럼」으로 나옵니다. 11월 25일에 바꾼 분류가 이미 반영돼 있습니다.
- 분류를 바꿔도 주소는 그대로입니다. 기사 번호만 쓰기 때문에 네이버에 걸린 링크가 깨지지 않습니다.
- 네이버로 보내는 전송 자료 안에 분류 코드가 따로 실리는지는 확인하지 못했습니다 (질문 1의 미확인 항목과 같습니다).

보고드릴 실수 1건
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

새 기사 작성 화면을 열자 CMS가 빈 기사 번호 1516913 을 하나 잡았습니다. 이 CMS는 화면을 열기만 해도 번호를 잡는데, 저장소에 적혀 있던 그 사실을 확인하지 않고 열었습니다.
- 저장하지 않았고, 공개 주소로 열면 「존재하지 않는 링크」로 나와 독자에게 보이지 않습니다.
- 「1516913 지워」라고 주시면 비어 있는지 다시 확인한 뒤 그 한 건만 지웁니다. 지시 전에는 건드리지 않습니다.

회원목록 화면 구조를 읽는 중에 회원 몇 명의 아이디와 성명이 제 작업 화면에 표시됐습니다. 메일 주소는 가렸고 어디에도 저장하지 않았습니다.
