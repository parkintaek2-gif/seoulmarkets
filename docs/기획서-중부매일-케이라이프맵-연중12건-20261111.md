## 🔴 첫 판에서 사장님이 바로잡으신 것 둘

### ① 「충청 지역 얘기 쓰지마」

2026-10-17 「충청권 연결하지 말랬지」와 같은 지시다.
데스킹 검사에도 **충청권끌어옴** 항목이 이미 서 있는데, 내가 기사와 기획서에
충청권 혼인 통계를 끌어다 붙였다. **열두 건에서 충청권을 전부 뺐다.**

⚠ 네이버 심사의 지역성 항목이 걸리지 않겠느냐는 물음이 남는다. 판단은 이렇다 —
심사가 막는 것은 **보도자료 단순 전재**이지 전국 자료가 아니다. 억지로 지역을 붙인
문단은 데스크가 이미 걸러내도록 되어 있고, 사장님이 두 번 같은 말씀을 하셨다.
⇒ **소재 자체가 전국인 것을 고르고, 지역을 덧붙이지 않는다.**

### ② 「손 없는 날과 결혼이 상관있다는 건 들어본 적이 없어」

확인했다. **사장님 말씀이 맞다.**

> 한국민족문화대백과사전 「택일(擇日)」 — 혼례식을 올릴 날짜를 정하는 절차
> 「택일방법은 오행을 아는 사람에게 부탁하여 신랑·신부의 **생기복덕(生氣福德)**을
>  가려서 '살'을 제하고 좋은 날을 택한다」

그 항목 전체에 **손 없는 날은 한 글자도 나오지 않는다.**
손은 방위를 돌아다니며 사람의 **이동**을 방해한다는 관념이라 쓰임이 **이사와 먼 길**이다.

⇒ 1회 기사에서 결혼을 전부 빼고, **그 오해를 바로잡는 것을 기사의 중심**으로 옮겼다.
⇒ `klifemap.ai/sonnal.html` 의 「이사·결혼 날짜 선택 전에」 표기도 함께 고친다.

## 열둘의 선정 기준

연중기획은 **열두 번을 버텨야 한다.** 그래서 「좋은 주제」가 아니라
**「열두 달치 자료가 이미 세상에 있는가」**로 골랐다.

```
① 공표된 공식 자료가 «이미» 있나   — 없으면 둘째 달에 멈춘다
② 우리가 «다시 세는» 축이 있나     — 받아쓰면 자체기사가 아니다
③ 소재 자체가 전국인가            — 지역을 덧붙이지 않는다 (사장님 지시)
④ 사람을 섭외하지 않고 굴러가나    — 사장님 지시: 사람을 거치는 계획을 세우지 않는다
⑤ 그달에 내야 할 «이유»가 있나     — 철과 맞아야 읽힌다
```

## 🔴 ③ 삼재 기사 — 사장님이 확정하신 것

> 「**삼재 띠를 알리되 삼재는 명리학에선 의미를 두지 않음을 명기해**」

```
✅ 그해 삼재에 드는 띠 셋이 무엇인지는 «적는다» — 사람들이 찾는 말이다
✅ 그 띠에 해당하는 사람이 몇 명인지 센다 — 아무도 안 센 수다
🔴 그리고 «반드시» 적는다 — 자평명리는 삼재를 판단 근거로 삼지 않는다
⛔ 「삼재니 조심하라」로 읽히는 문장을 한 줄도 쓰지 않는다
⛔ 부적·굿·살풀이로 이어지는 말을 쓰지 않는다 — 우리는 그것을 다루지 않는다
```

⭐ 이 구성이 우리 강령과 정확히 같다 — **사실을 내고 판단은 독자가 한다.**
  「삼재에 드는 띠는 이것이다」는 사실이고, 「그러니 나쁘다」는 우리가 할 말이 아니다.

## 왜 이 축인가 — 셋

### ① 받아쓰지 않고 «다시 센다»

열두 건 모두 공표된 수를 그대로 옮기지 않는다.
손 없는 날은 365일을 음력으로 바꿔 세고, 이름은 획수로 다시 묶고,
삼재는 띠를 인구에 곱한다. 이것이 네이버 자체기사 판정의 핵심이다.

### ② 열두 건이 서로 다른 축이다

```
날짜   ① ④ ⑫       이름   ② ⑤ ⑩
사람   ③ ⑧ ⑨       풍속   ⑥ ⑦ ⑪
```

같은 말을 열두 번 하지 않는다. 달마다 자료가 바뀐다.

### ③ 자료 공표 일정과 달이 맞는다

```
1월   행정안전부 주민등록 인구(연초 확정)   → ③ ⑧
연말  대법원 신생아 이름 통계              → ②
수시  사법연감 · 총조사 · 사회조사         → ⑤ ⑩ ⑪
상시  한국천문연구원 역서                  → ① ④ ⑥ ⑫
```

⚠ ⑦의 **일자별** 인구이동 자료는 공표 여부를 아직 확인하지 않았다.
  월별까지만 공개돼 있으면 월별로 쓰고, 일자별 수치는 싣지 않는다.
  ⛔ 일자별인 것처럼 쓰지 않는다.

### 🔴 사진 — 생성형 그림을 신문에 쓰지 않는다

중부매일 규정 — 「워터마크 등 클로드AI를 이용했다는 흔적이 **절대로** 남으면 안 됨」.

```
신문        중부매일DB · 연합뉴스 · 기관 공식 사진만 쓴다
기사 시각물  우리가 만든 «표·그래프»는 괜찮다 — 그림이 아니라 자료다
우리 채널   케이라이프맵 웹페이지·카드뉴스·사회관계망에는 생성형 그림을 쓴다
```
