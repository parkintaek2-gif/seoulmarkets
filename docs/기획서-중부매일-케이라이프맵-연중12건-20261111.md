# 중부매일 연중기획 — 케이라이프맵 축 열두 건

2026-11-11 · 5번 · 사장님 지시 「기사를 매달 한 건씩 내보낼 거니 기획을 잘 해봐」

---

## 열둘의 선정 기준

연중기획은 **열두 번을 버텨야 한다.** 그래서 「좋은 주제」가 아니라
**「열두 달치 자료가 이미 세상에 있는가」**로 골랐다.

```
① 공표된 공식 자료가 «이미» 있나        — 없으면 둘째 달에 멈춘다
② 우리가 «다시 세는» 축이 있나          — 받아쓰면 자체기사가 아니다
③ 충북·충청권으로 쪼개지나              — 전국 기사면 지역지가 쓸 이유가 없다
④ 사람을 섭외하지 않고 굴러가나          — 사장님 지시: 사람을 거치는 계획을 세우지 않는다
⑤ 그달에 내야 할 «이유»가 있나          — 철과 맞아야 읽힌다
```

⭐ 네이버 CP 심사의 「매월 카테고리별 심층보도 1건 이상」에서
   **문화·사회** 칸을 이 열둘로 채운다. 스포츠 연중기획과 겹치지 않는다.

## 왜 이 축인가 — 셋

### ① 받아쓰지 않고 «다시 센다»

열두 건 모두 **공표된 수를 그대로 옮기지 않는다.**
손 없는 날은 365일을 음력으로 바꿔 세고, 이름은 획수로 다시 묶고,
삼재는 띠를 인구에 곱한다. 이것이 네이버 자체기사 판정의 핵심이고,
우리 강령의 **「남들이 안 센 것을 세고, 측정하지 못한 것은 못했다고 적는다」**와 같다.

### ② 열두 건이 서로 다른 축이다

```
날짜   ① ④ ⑧ ⑨ ⑫      이름   ② ⑤ ⑩
사람   ③ ⑥ ⑦          집안   ⑪
```

같은 말을 열두 번 하지 않는다. 달마다 자료가 바뀐다.

### ③ 자료 공표 일정과 달이 맞는다

```
1월   행정안전부 주민등록 인구(연초 확정)        → ③
3월   국가데이터처 혼인·이혼 통계(3월 공표)       → ⑥ ⑦ 가 받아 쓴다
연말  대법원 신생아 이름 통계                    → ②
수시  사법연감 · 장사시설 통계 · 총조사          → ⑤ ⑪ ⑩
```

⚠ ⑧의 **일자별** 인구이동 자료는 공표 여부를 아직 확인하지 않았다.
  월별까지만 공개돼 있으면 **월별로 쓰고, 일자별은 못 봤다고 적는다.**
  ⛔ 일자별인 것처럼 쓰지 않는다.

## 달마다 지킬 절차

```
1. 그달 자료를 «공식 사이트»에서 직접 받는다 — 기사에서 베끼지 않는다
   (보도자료는 hwpx 원문을 열어 표를 읽는다. PDF 는 한글이 깨진다)
2. 합계·비율을 두 번 계산해 대조한다
3. 선행보도를 찾아 유사도를 적는다 — 30% 미만이어야 자체기사다
4. v7 로 데스킹한다 (docs/중부매일-자체기사-지침-v7.md)
5. 금지어 검사를 돌린다 — node scripts/순한글-금지어.mjs <파일>
6. 사진을 붙인다
```

### 🔴 사진 — 생성형 그림을 신문 기사 사진으로 쓰지 않는다

중부매일 규정 — 「워터마크 등 클로드AI를 이용했다는 흔적이 **절대로** 남으면 안 됨」.
생성형 도구로 만든 그림은 그 원칙과 정면으로 어긋난다.

```
신문    중부매일DB · 연합뉴스 · 기관 공식 사진만 쓴다
기사 시각물  우리가 만든 «표·그래프»는 괜찮다 — 그림이 아니라 자료다
우리 채널   케이라이프맵 웹페이지·카드뉴스·SNS 에는 생성형 그림을 쓴다
```

✅ 케이라이프맵 이름은 한 건에 한 번만 넣는다 — 많으면 홍보로 읽혀 심사에 불리하다
