# 사장님께 — 보시고 정해 주실 것

## 1. 이 양식이 맞습니까

세 페이지 모두 **①사실 표 → ②못 거둔 칸을 그대로 표시 → ③잰 날과 거둔 곳**으로 짰습니다.
빈 칸을 지어내지 않는 것이 이 분야에서 특히 중요하다고 봤습니다.
**채널번호나 재방송 시간이 틀리면 손님이 그 시간에 TV를 켭니다.** 그건 틀린 기사보다 나쁩니다.

## 2. 사진 — 말씀대로 넣겠습니다

사장님 — 「사진은 방송프로그램 내에 있는 걸 쓰면 됨. 채널 정보는 채널의 CI, BI, 대표 프로그램 사진을 써」

```
채널 페이지    그 채널의 CI·BI + 대표 프로그램 사진
프로그램 페이지  그 방송 안에 있는 사진 (방송사 공식 페이지에 올라온 것)
```

견본에는 아직 안 넣었습니다. 양식을 정해 주시면 사진까지 붙여 한 장을 완성해 올리겠습니다.

## 3. 제목 — 사장님 예시를 그대로 따랐습니다

```
JTBC 채널번호-편성표              ← 사장님 예시 그대로
전설의 사내 재방송-시청률-방송시간    ← 사장님 예시 그대로
라이어 등장인물-몇부작-시청률        ← 드라마는 제가 같은 형태로 지었습니다
```

드라마 제목 꼴은 제가 정한 것이라 **고쳐 주시면 그대로 바꾸겠습니다.**

## 4. 얼마나 만들 수 있나 — 재서 말씀드립니다

채널은 **수집 도구를 이미 만들었습니다.** JTBC 계열 셋에서 전국 12줄·지역 273줄을 거뒀습니다.
방송사마다 페이지 꼴이 달라 한 곳씩 붙여야 합니다. 한 방송사 집안을 붙이면 그 집 채널이 한꺼번에 나옵니다.

프로그램은 공식 페이지에서 회차·출연·줄거리까지 나오므로 같은 방법으로 늘립니다.
**다만 시청률과 재방송은 회차마다 따로 대조해야 해서 가장 느립니다.** 거기가 병목입니다.
