## 🔴 먼저 — 아침 지시서를 기다리지 않는다

```
2026-11-15 부터 11-19 까지 닷새 동안 날짜별 아침 지시서가 없었다.
그 닷새 동안 열린 콘텐트는 11-19 하루만 쳐도 0편이었다.
1번은 11월 14일 지시서로 일했고, 막힌 것을 쥔 채 하루를 기다렸다.
```

**이 파일이 그 자리를 영구히 대신한다.** 날짜별 `1번-<날짜>-아침.md` 는 더 만들지 않는다.
없는 파일을 기다리느라 멈추는 일이 다시는 없게 한다.

## 2. 한 편의 조건 — 「썼다」가 아니라 「열린다」까지

```
① 커밋되어 origin/main 에 올라갔다
② 배포되어 라이브 주소를 «직접 열어» 그 글이 보인다 — 빌드만 돈 것은 열린 것이 아니다
③ node scripts/순한글-금지어.mjs <그 파일> 이 0건으로 통과했다
④ 사이트맵·카탈로그에 들어갔고 색인 요청이 나갔다
```

- ⛔ 모아 두었다가 한꺼번에 배포하지 않는다. **세 편마다 배포하고 라이브를 눌러 본다**
- ⛔ 분량으로 채운 척하지 않는다. 그 사이트 글의 **중앙값**을 먼저 세고 거기에 맞춘다
  (KLifeMap 한국어 727편 중앙값 1,997자 · 하위 10%도 1,520자)
- ⛔ 확인 안 된 내용은 어떤 글에도 넣지 않는다. 못 쟀으면 그 줄을 **뺀다**
- ⛔ 순한글 조어·번역투·AI 말투 금지. **쓰고 나서가 아니라 쓰기 전에** 금지어를 본다
- ⛔ 평균을 규범으로 쓰지 않는다. 분포로 쓰고 「」를 둔다

## 3. 🔴🔴 업무분담 — 1번이 하는 것과 5번이 받는 것

**1번이 하는 것**

```
✅ 네 사이트 글쓰기 · 커밋 · 배포 · 라이브 확인 · 색인 요청
✅ 자기 계정으로 되는 중부매일 기사 작성과 데스킹
✅ 막힌 것을 «그 자리에서» 세션간 메모에 적고 다음 편으로 넘어간다
```

**5번(총괄)이 받는 것 — 1번은 여기서 기다리지 않는다**

```
🔵 중부매일 CMS 계정 한도(회차 줄 없음) · 승인·저장·웹출판
🔵 배포 열쇠가 안 나오거나 관문이 막는 것
🔵 엔진 값이 틀릴 때의 검산 (일진표·사주·궁합 엔진)
🔵 우리 아이피가 끊겨 403 이 날 때
🔵 다른 유닛 저장소를 건드려야 하는 것
```

⭐ **넘기는 법** — 세션간 메모에 `[1번 → 5번] 막힘:` 으로 한 줄 적고 **바로 다음 편으로 간다.**
   답을 기다리며 멈추지 않는다. 2026-11-19 에 1번이 「전달하기를 기다립니다」로
   하루를 보냈고, 그날 열린 글은 0편이었다. **기다리는 것은 일이 아니다.**

## 4. 수시 소통 — 사장님 지시

```
매시 정각    세션간 메모에 한 줄. 지금 몇 편이 열렸고 다음에 무엇을 하는지
막혔을 때    그 자리에서 바로. 정각을 기다리지 않는다
12:00·17:00  중간 보고
21:00        마감 보고 — 열린 편수
```

⛔ 「확인만 했습니다」로 한 시간을 넘기지 않는다.
⛔ 혼자 쥐고 있다가 21시에 「못 했습니다」로 내는 것이 가장 나쁘다.

## 5. 403 을 받으면

사이트가 죽은 것이 아니라 **우리 아이피가 끊긴 것**이다. 보안 점검기가 `/admin`·`/.env` 를
두드리면 침입막이가 10분에 열두 번을 넘겼다고 보고 끊는다.
⇒ 10분 뒤에 다시 연다. 그래도 403 이면 메모에 적고 다음 편으로 간다. **배포를 다시 하지 않는다.**

## 6. 무엇으로 끝났다고 판정하나

21:00 뒤에 5번이 `git log` 로 실제 커밋을 세고 라이브 주소를 **직접 눌러서** 연다.
「시켰다」로도 「했다고 적었다」로도 끝나지 않는다. **열리는 글의 수**가 그날의 성적이다.
