## Ⅴ. 사고를 내는 자리 넷 — **여기만은 틀리면 회사가 멈춘다**

```
⛔ klifemap 에 ctype apply 금지
   콘솔 환경변수가 통째로 지워진다. 2026-09-11 에 그래서 구글·네이버 로그인이 사라졌다.
   KLifeMap 배포는 Cloudtype «대시보드»에서 한다

⛔ ctype 은 예외 없이 -t, 그리고 «서 있는 폴더»가 짝이어야 한다
   SeoulMarkets   dataeconomics 폴더 · -t @parkintaek2/seoulmarkets:main · 앱 이름 web
   KLifeMap       klifemap 폴더      · -t @parkintaek2/klifemap:main     · 앱 이름 klifemap-app
   친 뒤 나오는 줄을 읽는다 — 앱 이름이 다르면 그 자리에서 ctype remove 한다

⛔ ctype remove 는 커스텀 도메인 연결까지 가져간다
   지우기 전에 ctype routes 로 붙은 도메인을 적어 둔다. 여섯이어야 한다

⛔ 셸 명령줄에 백틱이나 한글 변수명이 든 글을 올리지 않는다
   셸이 그것을 실행해 엉뚱한 배포가 뜬 적이 있다. 글은 편집 도구로 파일에 적는다
```
