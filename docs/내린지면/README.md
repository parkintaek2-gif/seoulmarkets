# 내린 지면 — 지우지 않고 까닭과 함께 둔다

여기 있는 `.astro` 는 **한때 손님에게 나가던 지면**이다. 지우지 않는 까닭은 둘이다 —
① 왜 내렸는지가 남아야 다음 사람이 같은 자리를 다시 파지 않는다
② 막힌 까닭이 풀리면 `src/pages/` 로 **그대로 되돌릴 수 있다**

> ⛔ 여기 파일을 고치지 않는다. 되돌릴 때 **그때 그대로** 돌아가야 한다.
> ⛔ 내릴 때는 **반드시 이 글에 한 줄 적는다.** 적지 않고 옮기면 그냥 잃어버린 것이다.

---

## 2026-11-10 · 5번 — 백년지도 값 지면을 내렸다 (사장님 지시)

```
docs/내린지면/price.astro    ← src/pages/100y/
```

사장님 — 「**그럼 유료지역 리포트 없애라고 전에 말했잖아**」

### 왜 내렸나

지역 한 벌은 **2026-09-10 에 이미 무료가 됐다**(`price.ts` 의 `미리보기그만`).
그런데 값 지면 하나만 살아남아 **「9,900원」을 세 번** 보여 주고 있었다(11-10 라이브 실측).

⭐ **팔지 않는 값을 적어 두면 그것은 거짓말이다.** 손님은 「어딘가에서는 파는구나」로 읽는다.
2026-09-12 에 사장님이 메뉴의 「유료서비스」 낱말을 똑같이 잡아 주셨는데,
그때 메뉴만 고치고 **지면은 그대로 뒀다.** 한 자리만 고치면 반드시 다른 자리가 남는다.

### 같이 뗀 것 — 지면 하나만 옮기면 안 끝난다

```
server.mjs                              301  '/100y/price' → '/region'
src/pages/100y/sitemap.xml.ts           /price 줄
src/pages/100y/index.astro              /price 로 가는 링크 둘 · 값 문단
src/pages/100y/report/area/[slug].astro 값표 · 사는 단추 · 「얼마에 파나」 링크
src/pages/100y/refund.astro             값(9,900원) 글자
```

⛔ `src/lib/price.ts` 는 **안 지웠다.** `한벌에드는것`(무엇이 들어 있나)처럼
파는 것과 상관없이 쓰는 낱말이 남아 있다. 지우면 지면 여럿이 같이 깨진다.

### 되돌리는 법

값을 다시 받기로 하면 `git mv` 로 `src/pages/100y/` 에 돌려놓고 위 다섯 자리를 같이 되살린다.
값표·사는 단추는 **이 커밋 바로 앞 판**(`git show`)에 통째로 있다.

## 🔴 내리는 일은 «세 자리»다 — 셋째를 빠뜨려 404 를 남겼다 (2026-11-09)

```
① 카탈로그에서 뗀다                     손님이 죽은 칸을 누르지 않게
② 사이트맵에서 뺀다                     구글에게 «새로» 내밀지 않게
③ server.mjs «사라진지면» 표에 넣는다    이미 아는 구글을 살아 있는 이웃으로 보내게
```

2026-10-11 에 아래 두 장을 내리면서 ①②는 했는데 **③을 빠뜨렸다.**

⭐ **사이트맵에서 빼는 것은 「구글이 잊는 것」이 아니다.** 「새로 알리지 않는 것」일 뿐이다.
이미 찾아 둔 주소는 계속 긁으러 오고, 404 를 받으면 그 자리의 검색 수요가 통째로 버려진다.
2026-09-03 에 K Culture Wire 에서 노출 5,010건의 **9.4%** 가 우리 404 로 가고 있었다.

그 결과 — 서치콘솔 「찾을 수 없음(404)」에 `/data/bank-loan-delinquency` 가 걸렸고
(마지막 크롤 2026-10-29), 1번이 10-26 에 올린 유효성 검사가 **11-07 에 이 장 때문에 실패**했다.

⛔ 같은 흠이 세 번째다 — 09-03(KCW 다섯 장) · 10-26(무역 글 한 장) · 11-09(`/data` 두 장).
세 번 다 「다음엔 꼭」이라고 적어 두었고 세 번 다 안 지켜졌다. 그래서 **검사로 옮겼다** —
`scripts/check-내린지면에-301이-걸렸나.mjs` (`run-all-checks` 안에서 돈다).
이 폴더에 `.astro` 를 넣고 표에 줄을 안 넣으면 검사가 선다.

⚠ 보낼 곳은 **뜻이 가까운** 살아 있는 페이지여야 한다. 홈으로 몰면 구글이 soft 404 로 깎는다.

## 2026-10-11 13:4x · 5번 — ECOS 901Y124(은행연합회) 승인이 안 났다

```
docs/내린지면/bank-loan-delinquency.astro          ← src/pages/data/
docs/내린지면/mortgage-balance-gender-gap.astro    ← src/pages/data/
```

### 왜 내렸나

둘 다 `src/data/korea-household-debt.json` **하나로만** 서 있는 지면인데, 그 안의 네 계열이
전부 **우리가 낼 수 있다고 판정되지 않은 것**이었다.

```
901Y124   은행연합회 작성   🔴 승인 필요 — ECOS 가 «배포»할 뿐 «작성»은 다른 기관이다
151Y001   ORG_NAME null    ⬜ 못 쟀다
181Y012   ORG_NAME null    ⬜ 못 쟀다
181Y015   ORG_NAME null    ⬜ 못 쟀다
```

⛔ **「ECOS 에서 받았다」가 허락이 아니다.** 허락은 `StatisticTableList` 의 `ORG_NAME`(작성기관)이 정한다.
우리는 광고를 싣는 매체라 「상업적 이용」에 든다.

⛔ null 을 「한국은행이겠지」로 읽지 않았다. 그것은 짐작이다.
2026-09-22 에 한국은행 통계정보팀에 물었고 **19일째 답이 없어** 10-11 에 재문의했다.
오늘 다시 조회해도 null 셋은 그대로였다.

### 왜 «내리는» 쪽으로 정했나 — 재 보고 정했다

```
/data/bank-loan-delinquency          질의 0개 · 노출 0 · 클릭 0   (GSC 2026-09-08~10-06)
/data/mortgage-balance-gender-gap    질의 0개 · 노출 0 · 클릭 0
```

⭐ **잃을 트래픽이 0이다.** 두고 틀리면 타 기관 자료를 영리 매체에 승인 없이 재배포한 것이 되고,
내리고 틀려도 잃는 것이 없다. 리스크관리의 자리 — 「**그것이 틀렸을 때 무엇을 잃는가**」.

⚠ 901Y124 만 빼고 나머지로 낼 수 있나도 봤다. **못 낸다** — 남는 셋이 전부 ⬜(못 쟀다)라
그것도 판정 없이 내는 것이 된다. 지면이 통째로 빈다.

### 되돌리는 법

둘 중 하나가 풀리면 `git mv` 로 `src/pages/data/` 에 돌려놓고, 아래 넷도 함께 되살린다.

```
① 은행연합회 승인을 받는다          ☎ 02-3705-5022
② 한국은행이 null 셋의 작성기관을 알려 준다
```

같이 되돌릴 것 — 내릴 때 함께 뗀 자리다.

```
src/pages/data/index.astro            목록 두 칸
src/pages/data/credit-balance.astro   본문 링크 한 줄
src/pages/data/real-wage-plateau.astro 본문 링크 한 줄
src/pages/sitemap-[section].xml.ts    사이트맵 두 줄
```

⚠ 되돌릴 때 `docs/라이선스-대장.tsv` 의 그 계열 줄도 함께 고친다 —
**지면을 되살리면서 대장을 그대로 두면 다음 사람이 또 같은 자리에 선다.**
