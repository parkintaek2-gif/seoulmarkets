## 2회 — 144경기 1위가 5경기에서 진 이유

**게재 11월 11일. 제목 후보** — 「타율 .286이 .207로…KT의 방망이가 멈춘 5경기」

### 답할 질문 하나

**정규시즌을 방망이로 1위 한 팀이, 왜 한국시리즈 5경기에서는 17점밖에 못 냈나.**

### 이미 확인한 것 (KBO 공식 기록실, 2026 한국시리즈)

| | 삼성 | KT |
|---|---:|---:|
| 팀 타율 | 0.291 | **0.207** |
| 득점 | 37 | 17 |
| 안타 | 53 | 36 |
| 평균자책점 | 3.06 | **6.00** |
| 피안타 | 36 | 53 |

정규시즌과 견주면 삼성은 타율 0.273에서 0.291로 올랐고, KT는 0.286에서 0.207로 내려갔다.
**리그에서 가장 잘 치던 팀이 다섯 경기 동안 가장 못 치는 팀이 됐다.** 이것이 기사의 축이다.

### 더 재야 하는 것

1. KT 주요 타자의 정규시즌 성적과 한국시리즈 다섯 경기 성적을 **같은 표에 놓는다.**
   누가 멈췄는지 사람 단위로 보여야 한다. 팀 타율만으로는 「운이 나빴다」와 구분되지 않는다.
2. 경기별 득점 흐름 — 1차전 KT 8-7 승 뒤 네 경기를 연속으로 졌다.
   **1차전과 2차전 사이에 무엇이 달라졌는지**를 득점·잔루·득점권 타율로 본다.
3. 삼성 투수진이 KT 타선을 어떻게 막았는지 — 선발·불펜 이닝 배분, 탈삼진 40개의 분포.
4. 정규시즌 2위가 1위를 꺾은 것이므로 **삼성의 1년**도 함께 적는다.
   삼성은 2025년 74승 68패 2무로 4위였고 올해 83승 58패 3무로 2위다. 9승 늘었다.

### 충청권 — 한화가 남긴 숙제

1회에서 「방망이는 리그 1위인데 마운드가 무너졌다」까지 숫자로 보여 줬다.
2회는 **그 마운드의 안쪽**을 본다.

- 한화 투수진의 2025 대 2026: 선발 평균자책점과 불펜 평균자책점을 갈라서 본다.
  (실점 554→835의 281점이 어디서 났는지, 선발인지 불펜인지)
- 세이브 16개·홀드 56개가 모두 리그 최저인 것 — **앞선 경기를 몇 번 지키지 못했는지**를
  역전패 수로 센다. 기록실에 없으면 경기 결과에서 직접 센다.
- 지난해 평균자책점 1위 마운드에서 **누가 빠졌고 누가 남았는지**를 등판 이닝으로 본다.

### 안 쓰는 것

- 감독·선수 우승 소감, 구단 평가, FA·이적 전망.
- MVP·수상 내역을 나열하는 단락. 기록에 비어 있으면 뺀다.
- 「내년에는」으로 시작하는 문장.

## 3회 — 디펜딩 챔피언은 3월에 무엇을 잃었나

**게재 11월 12일. 제목 후보** — 「탈삼진 97개가 사라졌다…WBC 다녀온 LG의 1년」

### 답할 질문 하나

**지난해 통합 우승팀 LG의 마운드가 1년 만에 평균자책점 3.79에서 4.81로 간 자리에 3월 WBC의 흔적이 남아 있나.**
**남아 있지 않다면 남아 있지 않다고 쓴다.**

### 이미 확인한 것 (1회 집계)

```
LG  2025  85승 56패 3무 1위  ·  팀 타율 .278(1위) · 평균자책점 3.79(3위) · 득실차 +204
    2026  78승 65패 1무 4위  ·  팀 타율 .264(8위) · 평균자책점 4.81(7위) · 득실차 -3
    탈삼진 1,080 → 983 (-97)  ·  피안타 1,236 → 1,379 (+143)
    세이브 50개·홀드 104개 — 둘 다 리그 최다
```

**탈삼진이 97개 줄고 피안타가 143개 늘었다**는 것은 같은 투수들이 지난해만큼
타자를 눌러 놓지 못했다는 의미다. 그 이유를 찾는 것이 3회다.

### 재는 방법 — 결론을 정해 놓지 않는다

1. **2월 6일 발표 WBC 최종 명단**으로 구단별 차출 인원을 센다.
   LG가 가장 많이 보냈다는 말이 사실인지부터 확인하고, 아니면 사실대로 고쳐 쓴다.
2. 차출 선수의 **2025년 기록 대 2026년 기록**을 같은 선수끼리 놓는다.
   (평균을 내지 않고 선수별로 늘어놓는다. 평균 하나는 분포를 가린다)
3. 같은 구단 **미차출 선수**도 같은 방식으로 놓는다. 두 묶음이 같은 방향으로 움직였다면
   WBC 때문이 아니다.
4. 부상자 명단 등재 **횟수와 일수**를 차출·미차출로 갈라 센다.
   ⛔ 부상의 원인은 구단 의료 정보라 기록으로 알 수 없다. 원인을 쓰지 않는다.
5. 투수는 **전년 대비 이닝과 등판 수**를 함께 본다. 3월에 더 던진 투수가 시즌에 덜 던졌는지.

### 쓰는 방식

- 차이가 보이면 **수치로** 적는다. 보이지 않으면 **「차이가 보이지 않았다」**로 적는다.
  보이지 않은 것을 보이는 것처럼 쓰지 않는다. 그것이 이 회차의 값이다.
- 한 선수의 부진을 WBC로 **단정하지 않는다.** 표 아래에 한 줄을 둔다 —
  **「이것은 기록이지 선수 개인에 대한 평가가 아닙니다.」**
- 한화도 같은 자리에서 본다. 한화는 2025년 평균자책점 1위에서 올해 9위로 내려갔다.
  LG와 같은 질문을 같은 방법으로 적용하면 **두 구단이 같은 이유인지 다른 이유인지**가 갈린다.
  이 비교가 3회의 충청권 몫이다.

### 안 쓰는 것

- WBC 경기 중계식 복기. 대회 성적은 배경 한 문단으로 끝낸다.
- 「후유증」·「체력 저하」 같은 말. 기록으로 이어지는 것만 쓴다.

## 사진 — 연합뉴스에서 찾는다 (사장님 2026-11-10 지시)

1회에서 쓴 방법을 그대로 쓴다.

```
찾기   연합뉴스 검색 → 사진 기사(PYH로 시작하는 번호)
적기   사진번호 · 촬영 기자 · 송고 일시를 원고에 적는다
캡션   설명. / 연합뉴스     ⛔ 「제공」을 쓰지 않는다
확인   열어서 눈으로 보고, 본 대로 설명을 쓴다
```

🔴 **연합뉴스 화면에서 뜨는 그림은 워터마크가 찍힌 판이다. 신문에 그대로 쓰면 안 된다.**
사진번호를 적어 두고 중부매일 연합뉴스 계정으로 원본을 받아 바꿔 넣는다.
1회 사진은 PYH20261103213600061(홍기원 기자, 11.3)이고 같은 문제가 걸려 있다.

사진 후보 — 2회는 삼성의 한국시리즈 우승 장면, 3회는 WBC 대표팀 또는 LG.
기사의 첫 문단과 맞는 장면을 고른다. 트로피 사진을 습관처럼 넣지 않는다.
