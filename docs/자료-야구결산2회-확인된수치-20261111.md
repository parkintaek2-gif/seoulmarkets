## 🔴 우리가 맞춘 수 — 기록실에 그대로 있지 않은 것

**이것이 자체기사를 가른다.** 기록실 수만 옮겨 적으면 자체기사가 아니다.

### KT — 144경기와 5경기

```
경기당 득점   정규 825÷144 = 5.73점   →   한국시리즈 17÷5 = 3.40점   (40.7% 줄었다)
경기당 안타   정규 1,441÷144 = 10.0개  →   한국시리즈 36÷5 = 7.2개
팀 타율      0.286(리그 1위)         →   0.207   (7푼 9리 내려갔다)
평균자책점    4.14                    →   6.00    (1.86 올랐다)
```

⭐ **리그에서 가장 잘 치던 팀이 다섯 경기 동안 가장 못 치는 팀이 됐다.**
⭐ 다만 **홈런은 KT가 5개로 삼성(2개)보다 많았다.** 길게 친 것이 아니라 **이어 치지 못했다.**
   안타 36개에 득점 17점 — 한 번 나간 주자를 불러들이지 못한 다섯 경기다.

### 삼성 — 반대쪽으로 움직였다

```
경기당 득점   정규 806÷144 = 5.60점   →   한국시리즈 37÷5 = 7.40점   (32% 늘었다)
팀 타율      0.273                   →   0.291

승수         2025 74승 → 2026 83승   (9승 늘었다)
```

### 🔴 충청권 — 한화 마운드의 «안쪽» (2회의 충청권 몫)


⭐⭐ **같은 기간 리그 전체 탈삼진은 11,024개에서 11,054개로 거의 그대로다.
리그는 안 변했는데 한화만 287개가 줄었다.** 이것이 한화 마운드 이야기의 중심 수다.
타고투저라서 내려앉은 것이 아니라 **한화의 투수가 타자를 못 눌렀다**는 뜻이다.

⭐ 볼넷 125개와 몸에 맞는 공 9개가 늘고 탈삼진 287개가 줄었다 —
   **주자를 스스로 내보내고 삼진으로 끊지 못한 1년**이다. 세이브 25개 감소가 그 결과다.

⭐ 견줄 자리 — LG는 탈삼진 1,080→983(97개 감소), 피안타 1,236→1,379(143개 증가).
   **방향은 같은데 폭이 한화가 세 배다.** 두 팀을 같은 표에 놓으면 이것이 보인다.
