# 사주 엔진의 절기 시각이 한국천문연구원보다 2~18분 «이르다»

```
찾은 날   2026-11-11 21:5x · 5번
어디      klifemap / sajuEngine.js — computeSajuFromDate 가 쓰는 태양황경 계산
무엇이    절기(節氣) 시각이 공식값보다 늘 «이르다». 2분에서 18분까지
왜 큰가   절기는 «월주가 바뀌는 자리»다. 입춘은 «연주가 바뀌는 자리»다.
          그 사이에 태어난 분은 여덟 글자 가운데 두 글자가 틀린 사주를 받는다.
          입춘 자리에서 틀리면 «띠»가 통째로 바뀐다.
```

## 어떻게 쟀나

한국천문연구원 달력자료의 24절기 표를 받아, 그 가운데 월주가 바뀌는 절기 열둘만
골라 엔진이 월주를 바꾸는 시각과 분 단위로 맞대어 보았다.

```
출처   https://astro.kasi.re.kr/kor/life/post/calendarData?search_year=2027
       같은 지면의 2026년 표
⚠ 그 지면에 「이 자료는 공식 발표 자료가 아닙니다. 공식 발표 자료는 월력요항을
  확인해주시기 바랍니다」라고 적혀 있다. 전자관보의 월력요항 본문은 아직 못 봤다.
  ⇒ 아래 수치는 «달력자료 기준»이다. 관보로 다시 대조해야 끝이다.
```

## 잰 결과 — 스물네 자리가 모두 한쪽으로 치우쳐 있다

```

경칩  -14분     백로   -3분             경칩  -6분      백로  -2분
청명  -17분     한로   -3분             청명  -5분      한로  -2분
입하  -18분     입동   -5분             입하  -5분      입동  -3분
망종  -15분     대설   -7분             망종  -5분      대설  -2분
```

⛔ **스물넷이 전부 음수다.** 한 번 어긋난 것이 아니라 계산식이 늘 이르게 나온다.
   들쭉날쭉이면 반올림 문제지만, 한쪽으로만 쏠리면 «식 자체»의 문제다.

## 무엇을 잘못 읽을 뻔했나

처음에 엔진이 낸 2027년 입춘 10시 40분을 그대로 기사에 쓰려 했다.
떠도는 값이 10:30 · 10:40 · 10:46 으로 갈려서 공식 지면을 찾아보지 않았다면
**우리 수치를 신문에 실을 뻔했다.** 사장님 「기사에서만 확인하지마. 공식 사이트에서
확인하는 습관을 가져」가 여기서 걸렸다.

## 얼마나 많은 분이 걸리나

한 해에 어긋나는 구간은 스물네 자리를 합쳐 2026년 약 121분, 2027년 약 50분이다.
한 해 525,600분 가운데 2026년 0.023%, 2027년 0.010%다.
수는 적지만 **틀린 쪽은 또렷하게 틀린다** — 입춘 자리에 걸리면 띠가 바뀐다.

## 다음에 할 일

```
1. 전자관보 월력요항으로 KASI 표를 한 번 더 대조한다
2. 태양황경 계산을 정밀한 식으로 바꾸거나, 24절기 시각표를 직접 쥔다
   (표를 쥐면 해마다 갱신해야 한다 — 그 갱신을 «검사»로 걸어 둔다)
3. 고친 뒤 위 스물네 자리를 다시 재서 전부 0분인지 본다
4. 그 재기를 자가시험으로 굳힌다 — 말로 된 규칙은 잊힌다
```

⚠ 이 파일은 «재 본 것»이지 고친 것이 아니다. 고치기 전에는 아직 틀린 채로 돈다.
