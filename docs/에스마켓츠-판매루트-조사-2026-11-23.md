## 2. 어디서 사고 있나 — 돈이 실제로 움직이는 자리

### 시장 크기와 구매 행태 (2025~2026 조사)

```
알트데이터 지출     2025년 28억 달러 · 전년 대비 17% 증가 (Neudata 집계)
쓰는 비율           응답 기관의 90%가 쓴다 · 3분의 2가 예산 100만 달러 넘는다
                   (Lowenstein Sandler 2025 설문)
```

### 사는 쪽이 공급자를 찾는 경로 넷

| 경로 | 어떻게 도는가 | 우리에게 맞나 |
|---|---|---|
| **데이터 스카우트** (Neudata 등) | 펀드가 구독료를 내고 공급자 목록을 받는다. **공급자 등록은 무료**이고 분석가가 2영업일 안에 검수한다 | ⭐ 가장 맞다 — 돈이 안 들고, 사는 사람이 모여 있는 유일한 자리다 |
| **데이터 장터** (Datarade · AWS Data Exchange · Snowflake) | 공급자가 상품을 올리고 문의를 받는다. Datarade 는 성사 수수료와 연간 등록 요금, AWS·Snowflake 는 판매자 등록이 필요하다 | 🟡 둘째 — AWS·Snowflake 는 손이 많이 간다 |
| **개발자 장터** (PyPI · MCP · Apify · RapidAPI) | 쓰는 사람이 직접 찾아 깔고 결제한다. 영업이 없다 | ⭐ 우리 손님이 영어권이고 **ChatGPT 유입이 구글의 수십 배**다 — 결이 맞다 |
| **컨퍼런스·소개** | 알트데이터 행사에 150개 공급자가 모인다 | ⛔ 지금은 아니다 — 비용과 시간이 든다 |

### ⚠ 사는 쪽이 어떻게 떨어뜨리는가 — 이것을 알고 들어가야 한다

```
트라이얼의 대부분이 탈락한다. 떨어지는 이유는 값이 아니라 셋이다
  ① 설명과 실제 자료가 다르다        — 받아 보니 말과 다르면 그 자리에서 끝난다
  ② 한계를 숨긴다                    — 못 받은 칸을 0으로 채우면 신뢰가 통째로 간다
  ③ 물어도 답이 느리다                — 방법론을 열어 설명하는 공급자만 살아남는다
```

⭐ **①②는 우리가 이미 하고 있는 것이다.** 「재 보고 안 되면 안 된다고 적는다」가 회사 강령이고,
지면마다 「못 쟀다」를 적어 왔다. 파는 자리에서는 그것이 **약점이 아니라 통과 요건**이다.

## 3. 경쟁사는 어디에 어떻게 파나

### (1) 한국 자료를 영어로 파는 곳 — 값이 공개된 것만

| 파는 곳 | 무엇을 | 값 | 어디서 파나 |
|---|---|---|---|
| **koreanpulse** | KRX 공시·외국인 보유·행동주의 공시, 영문 | **$29 / $79 / $249** 월 (Solo·Analyst·Desk) | PyPI · **MCP 서버** |
| oanor KRX API | KRX 시세 | 무료 등급 + **월 €16.2~** | 자기 사이트 |
| Apify KRX 스크레이퍼 | KRX+DART, 영문 칸 이름 | **1,000건당 $5** | Apify 장터 |
| EODHD | 60여 거래소 시세·재무 | 월 $19~$99.99 | 자기 사이트 |
| Financial Modeling Prep | 글로벌 커버리지 | 월 $139 (글로벌 등급) | 자기 사이트 |

🔴 **koreanpulse 가 가장 가깝다.** 파는 것이 우리와 거의 같고(공시·외국인 보유),
값이 **$29~$249** 다. 우리 값표는 $79 단건 / $990 이다 — **한 자리 비싸다.**

### (2) 큰 곳은 어떻게 파나 — 배달 방식이 곧 상품이다

```
CEIC      자기 플랫폼 + API. 그리고 FactSet · Haver · Snowflake 에 «얹어서» 판다
FactSet   클라우드 · 데이터피드 · API · 위젯 넷으로 배달한다
QUICK     영문 장터(콘텐츠 45종)를 두고, 무료 영문 지면을 깔때기로 따로 운영한다
Wind      영문 포털에 상품 28종 · 배달 채널 다섯
```

⭐ 배울 것 둘 —
**① 남의 플랫폼에 얹는 것이 자기 사이트보다 크다.** CEIC 도 자기 사이트만으로 안 판다.
**② 무료 영문 지면은 깔때기지 상품이 아니다.** QUICK 이 우리와 같은 구조를 이미 쓰고 있다.
