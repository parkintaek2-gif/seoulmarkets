## 메일 보내는 법 — **두 저장소 어디에서든 된다**

```bash
# 내 이름(2번 = admin)으로 나가게 한다. 안 주면 u5 이름으로 나간다
set "MAIL_FROM=admin@klifedesign.net"        # Windows cmd — 따옴표로 묶는다
MAIL_FROM=admin@klifedesign.net node scripts/send-mail.mjs \
  --받는곳=parkintaek2@gmail.com --제목="[2번] …" --글=본문.txt --첨부=보고.pdf --보낸다
```

```
⚠ 첨부를 여럿 붙일 때는 «쉼표»다 — --첨부=A.pdf,B.pdf
  --첨부 를 두 번 쓰면 «하나만» 붙는다(2026-09 에 겪었다)
⚠ 본문은 파일로 준다(--글=파일). 셸 명령줄에 긴 글을 올리지 않는다
⚠ klifemap 저장소의 scripts/send-mail.mjs 는 «다리»다 — 자는 dataeconomics 에 하나뿐이다.
```
