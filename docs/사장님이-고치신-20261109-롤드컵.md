## Ⅱ. 무엇이 달라졌나

### 1. 🔴 내가 **찾지 않은 맥락**을 넣으셨다 — 가장 큰 차이

```
더해진 것   「대회 4연패 도전도 끝났다」   (부제목과 리드, 두 곳에)
```

T1 이 롤드컵 4연패에 도전하고 있었다는 사실이다. **경기 기록에는 없고 대회 이력에 있다.**
나는 그날 경기 수치만 확인하고 그 팀이 무엇에 도전하고 있었는지는 보지 않았다.

⭐ **경기 기사를 쓰기 전에 「이 경기가 무엇을 걸고 있었나」를 찾는다** —
  연패 도전 · 연승 기록 · 첫 우승 도전 · 통산 몇 번째. 수치보다 이것이 제목을 정한다.

### 2. 제목은 결과보다 **의미**가 앞

```
내 판   T1, BLG에 1대3으로 져 롤드컵 4강 탈락…결승은 젠지-BLG
사장님  T1, 결승행 좌절 BLG에 1대3으로 져…결승은 젠지-BLG
```

### 3. 팀에 **리그 이름**을 붙인다

```
내 판   BLG는 15일 오전 4시 결승에서 젠지와 만난다
사장님  BLG는 결승에서 LCK의 젠지와 맞붙는다        ← 「중국의 BLG」와 짝을 맞추셨다
```

### 4. 🔴 설명하는 도입 문장을 **또** 지우셨다 — 세 표본에서 세 번째다

```
지워진 것   「흐름은 3세트에서 다시 넘어갔다. BLG가 …」 → 「3세트에서 BLG가 …」
```

농구에서는 「두 팀은 득점하는 자리가 정반대였다」를, 배구에서는 「차이는 공을 받아 올리는 데서
났다」를 지우셨다. **같은 잘못을 세 번 했다.** 수치 앞에 해설을 붙이는 버릇을 버린다.

### 5. 한 줄 문단으로 흐름을 끊으신다

```
더해진 것   「T1은 그러나 3세트와 4세트를 잇따라 내줬다.」
```

날씨 기사에서 쓰시던 장치(「비 소식은 없다」)를 경기 기사에도 쓰신다.
**승부가 기우는 자리 앞에 한 줄을 세운다.**

### 6. 문장의 주어를 팀으로 되돌리신다

```
내 판   T1은 2세트를 되찾아 1대1을 만들었다
사장님  2세트를 이기며 T1은 1대1 동률을 만들었다

내 판   1세트부터 밀렸다
사장님  T1은 이날 1세트부터 밀렸다
```

### 7. 사진 제목

```
내 판   T1과 BLG
사장님  T1과 BLG 선수        ← 「선수」를 붙이셨다
```

## Ⅲ. 세 표본을 합쳐 — 경기 기사를 쓸 때 이 순서로 본다

```
0  🔴 이 경기가 «무엇을 걸고 있었나»를 먼저 찾는다 — 연패 도전·연승·첫 우승·통산 기록
1  제목 = 결과보다 «의미»를 앞에 (결승행 좌절 · 3연승 · 개막 뒤 첫 패배)
2  부제목 = [대회 이름] + 누가 무엇을 해서 어떻게 됐다. 경기 내용은 안 넣는다
3  사진 제목 = 팀 이름 + 「선수」. 장면 설명을 하지 않는다
4  리드 첫 문장에 대회 정식 이름. 팀에는 리그·나라 이름을 붙인다
5  쿼터·세트마다 «그 점수»와 «누적 점수»를 같이 쓴다
6  승부가 기우는 자리 앞에 «한 줄 문단»을 세운다
7  ⛔ 수치 앞에 해설을 붙이지 않는다 — 세 표본에서 세 번 지적받았다
8  센 표현은 «승부가 갈린 대목»에만. 선수 기록 나열은 담백하게
9  용어와 수치는 그대로 쓴다. 쉽게 풀어 쓰지 않는다
10 합계가 맞는지 보여 주는 계산은 뺀다. 비교되는 수치만 남긴다
11 겹치는 것·무관한 것·상대 팀 일정은 뺀다
```

⛔ **쓰지 않는 것** — 득점 우위 시간 · 관중 수(매진 제외) · 경기 총 시간 ·
  그날 경기가 없던 팀 이야기
