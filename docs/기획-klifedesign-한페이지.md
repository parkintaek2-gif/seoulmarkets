# KLifeDesign 회사 홈페이지 — 한 페이지 기획

사장님 2026-11-22 — 「우리가 운영하는 사이트는 케이라이프맵에이아이, 백년지도, 서울마켓츠이다. **여기에 케이라이프디자인 회사 홈페이지를 한 페이지로 만들게 기획해라**」

주소는 **klifedesign.net** 입니다. 지금은 홈페이지가 없어서 어디에도 링크를 걸지 못하고 있습니다. 이 한 페이지가 생기면 걸 수 있습니다.

---

## 1. 이 페이지가 하는 일은 하나입니다

**「KLifeDesign 이 무엇을 하는 회사인가」에 30초 안에 답하는 것**입니다.

회사 홈페이지를 찾아오는 사람은 넷입니다.

| 누가 | 무엇을 확인하러 오나 | 이 페이지가 줄 답 |
|---|---|---|
| 손님 | 결제한 서비스를 만든 곳이 실재하는가 | 회사 정보·연락처·서비스 셋 |
| 제휴처(언론사·기관) | 같이 일해도 되는 곳인가 | 하는 일·실적·연락처 |
| 검색엔진·AI | 이 회사는 무엇인가 | 구조화 데이터로 또렷하게 |
| 입사·협업 문의 | 어떤 회사인가 | 철학 한 문단 |

**⛔ 이 페이지는 서비스를 파는 자리가 아닙니다.** 파는 일은 세 사이트가 합니다.
여기는 **그 셋이 한 회사의 것임을 보여 주는 자리**입니다.

## 2. 담을 것 — 위에서 아래로 여섯 칸

```

사람이 스스로 길을 정하도록, 지형을 그립니다.
```

## 3. 어떻게 만드나 — 기술

### 택한 길: web 통에 라우팅 하나를 더한다

```
지금   seoulmarkets.com  ┐
      100yearmap.com    ├→ web 통 하나 (node:3000)
      kculturewire.com  ┘
더함   klifedesign.net   ┘  ← 라우팅 하나만 더하면 됩니다
```

서버가 Host 를 보고 페이지를 가르는 구조가 이미 있습니다. 한 페이지라 자료도
데이터베이스도 필요 없습니다. **새 통을 띄우지 않습니다** — 계정 메모리가 2GB
한도에 차 있어서 통을 더 띄울 자리가 없습니다.

### 만드는 데 드는 것

```
새 통          필요 없음
새 비용        없음
작업           페이지 1장 + 라우팅 1개 + 서버 분기 1줄
걸리는 시간    반나절
```

### ⚠ 지금 막혀 있는 것

컨테이너 배포가 2026-11-20 부터 계정 메모리 부족으로 실패하고 있습니다.
**이것이 풀려야 라우팅을 더할 수 있습니다.** 따로 올립니다.
