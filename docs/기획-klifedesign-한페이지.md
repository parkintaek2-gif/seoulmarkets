## 1. 넣는 것 — 둘뿐입니다

```
① 회사 소개
② 사이트 세 개 안내 카드 (각 카드에 주소 링크)
```

⛔ 다른 칸은 넣지 않습니다 — 뉴스·채용·문의·연혁·콘텐트 전부.
회사 정보(주소·연락)는 **케이라이프맵과 같은 것**을 씁니다.

문안은 정본 파일에 있습니다. 백년지도와 서울마켓츠 카드 문장은 **사장님 말씀을
기다리고 있습니다.** 임시 문장이 들어가 있으니 정하시면 바꿉니다.

---

## 2. 어디에 만드나 — 접은 K Culture Wire 자리를 씁니다

사장님 — 「**KCW 가 쓰던 리소스(서버·배포 자리)로**」

```
지금   seoulmarkets.com   ┐
      100yearmap.com     ├→ web 통 하나 (node:3000)
      kculturewire.com   ┘  ← 접었습니다
바꿈   klifedesign.net    ┘  ← 이 자리를 씁니다
```

라우팅 7개 가운데 K Culture Wire 가 2개(`kculturewire.com`·`www.kculturewire.com`)
입니다. 그 둘을 klifedesign.net 으로 돌리면 됩니다.

```
새 통          띄우지 않습니다
새 비용        없습니다
작업           페이지 1장 + 라우팅 2개 돌리기 + 서버 분기 1줄
```

⚠ K Culture Wire 의 이미 색인된 페이지는 라우팅을 돌리면 열리지 않게 됩니다.
그대로 둘지 어떻게 할지 따로 여쭙겠습니다.
