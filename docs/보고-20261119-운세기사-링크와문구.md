주요 수정은 다음과 같습니다.

- 「열두 띠가 모두 여기 있습니다 … 날마다 다시 냅니다」
  → 「십이지 열두 띠를 모두 수록했습니다 … 매일 갱신합니다」
- 「관계가 섭니다」 → 「관계가 성립합니다」
- 「생년을 갈라 적습니다」 → 「생년을 구분해 기재합니다」
- 「못 재는 것」 → 「이 화면이 다루지 않는 범위」
- 「지지 관계로 셈한 자료 … 당신을 정해 주는 글이 아닙니다」
  → 「지지 관계를 계산한 자료 … 개인을 단정하는 글이 아닙니다」
