# 비상벨 — 버그가 생기면 바로 조치하는 체계

> 사장님 지시(2026-08-31): *"어떤 버그가 생길 때 바로 조치할 수 있는 비상벨 같은 걸
> 만들어봐. 만든 뒤 모든 유닛이 활용할 수 있게 해."* — 1번이 klifemap 몫으로 처음 만들고,
> **전 유닛이 같은 틀로 자기 사이트에 복사**해 쓰는 것을 목표로 한다.

## 핵심 — 새 알림 채널을 안 만들었다

klifemap `server.js` 의 `POST /api/owner/notify` 가 **이미 6유닛이 함께 쓰는 창구**다
(코드 주석: "여섯 유닛이 저마다 다른 셸에서 부를 창구다"). 사장님 메일로 즉시 간다.
비상벨은 이 창구를 **자동으로, 사람이 안 봐도 부르는** 감시기를 얹는 것뿐이다.

```bash
curl -s https://klifemap.ai/api/owner/notify \
  -H "Content-Type: application/json" -H "x-admin-key: <SAJU_ADMIN_KEY>" \
  -d '{"title":"제목(영문 필드명 title/text/from 을 쓴다 — 한글 필드명은 셸 인코딩으로 깨진 전례가 있다)","text":"내용","from":"어느 유닛"}'
```
⛔ **`제목`·`내용`·`보낸이`(한글 필드명)도 서버는 받지만, 셸(Git Bash 등)을 거치며
인코딩이 깨져 "제목이 없습니다"가 난 전례가 실제로 있다. 반드시 영문 필드명을 쓴다.**
하루 한도 30건(넘으면 429). 급하지 않은 것을 자꾸 부르면 진짜 비상이 묻힌다.

## 자동 감시기 — `tools/check-emergency.mjs` (klifemap)

klifemap.ai 의 **"죽으면 매출이 바로 멈추는 자리"만** 골라 재고(홈·서버헬스·결제견적·
토스상태·체크아웃화면·사주화면), 하나라도 깨지면 ① 위 알림창구를 부르고 ② 이 파일에
아래 형식으로 한 줄 남긴다.

```
node tools/check-emergency.mjs           # 한 번 재고 끝낸다
node tools/check-emergency.mjs --조용히  # 정상이면 조용히(크론용)
```

⭐ **다른 유닛도 이 파일을 그대로 복사해 `BASE`(자기 사이트 주소)와 `검사목록`
(자기 사이트의 "돈 걸린 핵심 경로")만 바꾸면 된다.** 콘텐츠 지면·부가 기능은 넣지
않는다 — 전부 재면 느려지고, 느리면 아무도 안 돌린다.

⚠ **처음 만들 때 도장(거짓경보)을 하나 잡았다** — 결제 견적·토스상태 API는
`x-admin-key`가 아니라 `x-api-key`(손님 열쇠)가 필요한데 몰라서 401을 "사이트가
깨졌다"로 잘못 알릴 뻔했다. 새 감시기를 만들 때는 **반드시 정상 상태에서 먼저
초록불을 확인**하고, 그다음 일부러 하나를 깨뜨려 빨간불이 실제로 뜨는지도 확인한다.

## 로그 규칙

- 이 파일은 **누적 로그**다 — 지우지 않는다. 새 사고는 맨 아래에 덧붙인다.
- 형식: `## 🔴 <사이트> — <YYYY-MM-DD HH:MM>` + 무엇이 깨졌는지 줄마다.
- 해결되면 그 항목 아래에 `✅ 해결 <시각> — <누가 무엇을 고쳤나>`를 한 줄 더한다.
- 자가시험(일부러 깨뜨려 본 것)은 로그에 안 남긴다 — 진짜 사고만 남겨야 이 파일이
  "지난번에 몇 번 났나"를 보여주는 진짜 기록이 된다.

### 결함 ① — 「전부 빨강」을 사고로 읽었다

**사이트 여섯 곳이 같은 순간에 죽는 일은 없다. 끊긴 것은 «연결 하나»다.**
`fetch failed` 는 HTTP 오류가 아니라 «닿지도 못했다»는 뜻이다(DNS·소켓).

⚠ 더 뼈아픈 것 — `check-emergency-kcw.mjs` 안에 이미 이렇게 적혀 있었다.
  「자를 먼저 의심한다 — 모든 지면이 빨강이었고, 그것이 자의 흠이라는 신호였다.」
  그 교훈이 **«한글 누출» 검사에만 걸려 있고 «가용성» 검사에는 없었다.**
  ⇒ 겪어서 적은 규칙을 한 자리에만 걸면, 옆 자리에서 같은 사고가 다시 난다.

### 결함 ② — 로그 시각이 UTC 였다

19:40 사고가 로그에 **「10:40」**으로 남았다. `new Date().toISOString()` 이다.
CLAUDE.md 가 「toISOString() 금지 · 9시간 더하기 금지」를 못박았는데 **벨 넷이 다 어기고 있었다.**
⚠ klifemap 벨은 `Date.now() + 9시간` 뒤 toISOString 이라 «이 PC 에서만» 우연히 맞는다 —
  UTC 로 도는 기계에 올리면 아홉 시간 앞선 시각을 찍는다.
