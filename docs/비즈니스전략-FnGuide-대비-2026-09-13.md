## Ⅰ. 먼저 숫자를 바로잡는다 — FnGuide 실측

### 1-1. 사장님 말씀과 실제가 다르다

```
사장님 말씀    매출 600억 · 영업익 300억 가까이
실측           매출 354억 · 영업익 106.6억        (2025년 · 연결 · 사업보고서)
```

**매출은 1.7배, 영업익은 2.8배 차이**다. 사장님이 보신 수치가 전망치이거나 다른 항목일
수 있다. 다만 **이 수치가 우리 목표의 기준선이 되므로** 정확한 값에서 출발해야 한다.

⛔ 600억으로 잡고 세운 전략과 354억으로 잡고 세운 전략은 다른 물건이 된다.

### 1-2. 출처 — 우리가 매일 쓰는 우물이다

```
전자공시(DART) opendart.fss.or.kr  fnlttSinglAcntAll
회사           에프앤가이드 (코스닥 064850 · DART 고유번호 00331016)
보고서         사업보고서(11011) · 연결재무제표(CFS)
```

⛔ 블로그·검색 요약에서 가져오지 않았다. 원전에서 직접 받았다.

### 1-3. 5개년 — 이 회사가 어떻게 자랐나

| 해 | 매출액 | 영업이익 | 당기순이익 | 영업이익률 | 매출 성장 |
|---|---|---|---|---|---|
| 2021 | 255.2억 | 51.1억 | 54.7억 | 20.0% | — |

**연평균 성장 8.5%.** 영업이익률이 20% → 30% 로 올랐다.

### 1-4. 이 두 수가 사업의 성격을 말한다

```
영업이익률 30%   한 번 만들어 여러 번 파는 장사다
                 사람을 늘리지 않고 매출을 늘릴 수 있다
성장 8.5%        국내 시장이 이미 포화다. 폭발 성장이 없다
```

⭐ 앞의 것은 우리 경영원칙(**「사람을 거치는 계획을 세우지 않는다」**)과 정확히 맞는다.
  뒤의 것은 **국내에 머물면 우리도 같은 천장을 만난다**는 뜻이다.

## Ⅱ. 우리 상품은 지금 어디에 있나

### 2-1. 서울마켓츠 — 파는 것이 있으나 «살 수가 없다»

| 상품 | 값 | 상태 |
|---|---|---|
| 지면 · 표본 | Free | 열려 있다 |
| 단일 데이터셋 | KRW 390,000 | **1회성** |
| 단일 + 1년 | KRW 1,200,000 | 12개월치 릴리스 |
| 전체 6종 + 1년 | KRW 3,600,000 | 12개월치 릴리스 |
| 학술 | KRW 90,000 | 1회성 |
| 무역 데이터셋 | $29 one-time | 여기만 달러 |
| API | Free · Pro $99/mo | 여기만 월간 |

🔴 **결제 경로가 없다.** 지면에 이렇게 적혀 있다 —

```
Email admin@klifedesign.net with the dataset name and your organisation.
We send an invoice.
Pay by bank transfer. Invoiced in KRW.
```

⛔ 카드도 페이팔도 없다. **사람이 메일을 읽고 인보이스를 만들어야 한다** —
  우리 경영원칙 「사람을 거치는 계획을 세우지 않는다」를 정면으로 어긴다.
⛔ 원화 계좌이체뿐이다. **영어권 손님은 살 방법이 없다.**
⛔ 요금 단위가 섞여 있다 — 1회성·12개월·월간이 한 표에 뒤섞여 사장님도 헷갈리셨다.
   사장님이 헷갈리시면 손님은 반드시 헷갈린다.

### 2-2. 사업자가 갈려 있다 — 원화 결제의 걸림돌

```
서울마켓츠 발행 주체   범진아카데미            사업자 233-06-03536
토스 계약 사업자       주식회사 케이라이프디자인   사업자 456-87-03384
```

⇒ 토스(원화)를 그대로 붙이면 **남의 명의로 받는 것**이 된다.
  ✅ 다만 서울마켓츠 손님은 영어권이므로 **페이팔(달러)만으로 먼저 열어도 장사는 된다.**
  원화는 사장님이 명의를 정하신 뒤에 붙인다.

### 2-3. KLifeMap — 결제는 살아 있다

```
토스(원화)   live=true · 라이브 키로 돌고 있다
페이팔       꺼져 있다 — 해외 손님은 못 산다
```

### 2-4. 실측된 잠재고객 — **110곳**

```
우물    archive/raw/dart-ownership/ownership.ndjson
        대량보유(5%룰) 공시 · 2,547종목 · 21,785건
고른 법 보고자 이름이 라틴 문자이고 기관 꼴인 것만 (사람 이름은 뺐다)
결과    110곳   그 가운데 한국 종목 2곳 이상 보유 = 24곳(1순위)
```

**추측 명단이 아니라 공시 사실이다.** 이들은 스스로 「한국 주식을 5% 넘게 들고 있다」고
신고했고, 한국어를 못 읽는다. 잠재고객의 정의와 정확히 겹친다.

🔴 **그런데 아직 한 곳도 접촉하지 않았다.** 보낸메일 기록 75줄을 다 봤고 나스닥 한 건뿐이다.
  명단만 만들고 멈춰 있다.

### 3-1. 정직한 결론

**자료와 축은 이미 겨룰 만하다. 파는 구조가 없다.**
FnGuide와 우리의 차이는 «데이터 품질»이 아니라 **「손님이 살 수 있느냐」** 한 가지다.

⇒ 지금 가장 값이 큰 일은 새 데이터셋을 만드는 것이 아니라 **결제를 붙이는 것**이다.

## Ⅳ. 영어 기반이면 시장이 큰가 — 잰 것과 못 잰 것

### 4-1. ✅ 잰 것

```
한국 주식 5% 이상 보유 «외국 기관»   110곳   (DART 대량보유 공시 · 실명)
그 가운데 2종목 이상                  24곳
```

이 110곳만으로 세우는 하한 —

```
110곳 × KRW 1,200,000 (단일+1년)  =  13.2억
110곳 × KRW 3,600,000 (전체+1년)  =  39.6억
```

### 4-2. ⬜ 못 잰 것 — 그대로 적는다

```
⬜ 5% «미만» 보유 기관 수 — 공시 의무가 없어 우리 자료로는 못 센다.
   실제 시장은 110곳보다 훨씬 크지만 «얼마나» 큰지 못 쟀다
⬜ 영어권 금융데이터 시장의 총 규모
⬜ 한국 데이터만 사는 해외 기관의 지불 의사 금액
```

⛔ 못 잰 것을 짐작으로 채우지 않는다. **다음에 할 일**은 이 셋을 재는 것이다 —
  외국인 보유 비중(공공데이터포털)과 MSCI EM 내 한국 비중으로 근사할 수 있다.

### 4-3. 그래도 방향은 분명하다

```
FnGuide 2025 매출      354억   ← 한국 금융데이터 1위가 이 정도다
회사 목표 (2031년)   2,000억   ← FnGuide 의 5.6배
```

**한국 1등을 통째로 삼켜도 354억이다.** 국내 시장만으로는 산술이 성립하지 않는다.
사장님이 「영어 기반이면 시장이 훨씬 크지 않나」라고 하신 것 — **그 길밖에 없다.**

## Ⅴ. 목표 매출과 경로

### 5-1. 🔴 기존 계획이 회사 목표와 어긋나 있다

```
docs/매출계획-2026-2033.md   500억 / 2032~33년
조직 지침(사장님)             2031년 2,000억
```

**4배 차이다.** 둘 중 하나는 고쳐야 한다. 이 문서는 **사장님 목표(2031년 2,000억)**를
기준으로 쓴다.

### 5-2. 2,000억이 되려면 무엇이 참이어야 하나

```
1. 손님이 «달러로 그 자리에서» 살 수 있어야 한다        ← 지금 0. 이것부터다
2. 상품이 «구독»이어야 한다 — 1회 판매로는 복리가 없다
   FnGuide 가 월간·연간으로만 파는 까닭이 이것이다
3. 손님이 한국 기관이 아니라 «전 세계 기관»이어야 한다
4. 사람을 늘리지 않아야 한다 — 영업이익률 30%+ 를 지켜야 산술이 선다
```

### 5-3. 값 다시 매기기 — FnGuide를 자로 쓴다

FnGuide 상품당 월 11만~33만원(연 132만~396만원)이다. 우리는 영문·해외 기관 대상이므로
**달러로 매기고 구독으로 바꾼다.**

| 층 | 무엇 | 제안 값 | 근거 |
|---|---|---|---|
| Free | 지면·표본 | $0 | 깔때기 |
| Single | 데이터셋 1종 구독 | **$99/mo · $990/yr** | FnGuide 단품 월 11만원(≈$80)과 같은 자리 |
| All | 6종 전부 구독 | **$299/mo · $2,990/yr** | FnGuide 전체 묶음 대비 낮게 — 후발이다 |
| Academic | 논문용 1종 | **$79 one-time** | 지금 KRW 90,000 과 같은 자리 |
| API | Pro | **$99/mo** | 지금 값 유지 |

⚠ 달러 값은 **환율로 지어내지 않는다.** 위는 «새로 정한 값»이고, 페이팔이 받는 금액과
  화면의 값이 반드시 같아야 한다.

### 5-4. 2,000억까지의 산술 — 무엇이 몇 개 필요한가

```
All 구독 $2,990/yr ≈ 연 400만원
2,000억 ÷ 400만원 = 5만 구독
```

🔴 **5만 기관은 없다.** 전 세계 자산운용사가 대략 수만 곳이고 그중 한국을 보는 곳은
일부다. ⇒ **데이터 구독만으로는 2,000억이 안 된다.** 정직하게 적는다.

그래서 층이 더 필요하다 —

| 갈래 | 무엇 | 2031년 몫(안) |
|---|---|---|
| ① 데이터 구독 | 위 표 | 200~400억 |
| ② 지수(Index) | 우리 축으로 만든 지수의 라이선스·ETF 연동 | 500억+ |
| ③ 리포트·컨설팅 | 사람 축 리포트, 맞춤 분석 | 100~200억 |
| ④ KLifeMap | B2C 상담·구독 (0~100세) | 500억+ |
| ⑤ 광고 | 백년지도·KCW | 100억 |

⭐ **가장 큰 몫은 ②와 ④다.** 데이터 구독은 «기반»이지 «목표»가 아니다.
  ②는 `docs/매출계획-2026-2033.md` 에 이미 설계가 있다(지수 사업의 관문이 사라졌다는 절).
  ④는 사장님이 「0살~100살이 다 고객이다」라고 못박으신 그 갈래다.

⬜ 이 배분은 **아직 계산기로 검증하지 않았다.** 다음 작업에서 연도별로 세운다.
